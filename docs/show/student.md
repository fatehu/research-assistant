# 学生 (Student) 角色功能说明

学生是系统中的主要学习者和研究者，利用 AI 工具辅助学术研究，并与导师及同门协作。

## 1. 师生连接与学术融入 (Mentorship & Peer Context)
- **导师申请机制**：
    - 在导师库中搜索研究方向匹配的导师。
    - 提交申请意向并跟踪审批状态（待处理、已接受、已拒绝）。
- **学术团队融入**：
    - **同门动态**：查看同组同学 (Peers) 的概况。
    - **小组身份**：加入导师创建的研究组，继承对应的小组资源权限。

## 2. 沉浸式科研工具 (Deep Research Tools)
- **AI 引导式阅读体验 (Experience V2)**：
    - **叙事弧线 (Narrative Arcs)**：系统根据论文逻辑自动生成引导流程，不再是盲目提问。
    - **构件草案 (Artifact Drafts)**：AI 协助从文献中提取知识块并形成可复用的草案。
- **智能文献管理**：
    - PDF 解析与智能标注。
    - 支持多端同步的论文收藏与阅读报告。
- **AI Notebook (CodeLab)**：
    - 集成 Python 执行内核，各单元格 (Cell) 共享命名空间。
    - AI Agent 会话历史持久化，辅助进行代码编写与实验分析。

## 3. 资源获取与学习 (Learning Resources)
- **共享库自动同步**：自动接入导师共享的知识库、文献集或 Notebook。
- **知识库 RAG 增强**：个人知识库支持全文检索与向量检索，并能继承导师/小组的共享背景。
- **实时公告**：获取导师发布的最新学术动态，支持已读/未读状态管理。

## 4. 使用限制与规范 (Compliance)
- **并发资源限制**：根据系统配置，单用户拥有受限的代码执行并发槽位，确保系统稳定性。
