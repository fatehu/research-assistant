# 导师 (Teacher/Mentor) 角色功能说明

导师是研究团队的核心，负责引导学生、管理研究小组以及共享学术资源。

## 1. 学生与导师组管理 (Mentorship & Groups)
- **师生关系握手 (Mentorship Handshake)**：
    - **审批申请**：导师可以在团队页面查看并回复学生的加入申请 (Accept/Reject)。
    - **主动邀请**：通过邮箱精准邀请学生，支持附带个性化邀请信息。
- **进度与活动全景监控**：
    - **多维统计**：实时查看学生的对话、知识库、论文阅读、Notebook 实验等量化指标。
    - **深度动态流**：精确到“更新了代码单元”、“上传了特定文献”的实时 feed，掌握科研动态。
- **科研小组 (Research Groups) 治理**：
    - 创建具有不同研究方向的小组。
    - 设定小组容量，管理成员进出。

## 2. 增强型资源共享 (Advanced Sharing)
- **分级权限控制**：
    - 将知识库、文献集或 Notebook 共享给特定个人、整个小组或“名下全体学生”。
    - 设置读写权限，实现协作科研。
- **AI 智能工具上下文**：
    - 导师在使用 AI 助手时，系统会自动聚合关联研究组的背景知识。

## 3. 辅助教学与交流 (Communication & Teaching)
- **公告系统**：
    - 向学生/小组精准推送学术通知。
    - 支持公告置顶与已读状态统计。
- **科研体验引导 (Reading Experience)**：
    - 了解系统提供的 AI 引导式阅读（Experience V2），通过叙事弧线 (Narrative Arcs) 帮助学生理解复杂文献。

## 4. 高级权限 (Privileges)
- **Tool Registry 优先权**：在 AI 代理工具箱中，导师角色拥有更高或更专用的工具执行权限。
