# 管理员 (Administer) 角色功能说明

管理员负责整个系统的运行维护、用户安全和全局资源监控。

## 1. 用户与权限全权治理 (User & Access Control)
- **全局用户管理**：管理所有导师、学生及初级管理员的账号。
- **角色流转逻辑**：
    - 精确处理角色变更（如导师转学生、学生留校转导师）时的关系解绑与数据迁移。
- **状态管控**：包括账号禁用、权限回收及批量操作。

## 2. 数据整合与维护 (Data Integrity & Maintenance)
- **乱码修复 (Mojibake Repair)**：系统内置针对文献标题、描述中编码问题的自动修复机制。
- **文献集治理**：合并重复的默认文献集（如“收藏”、“待读”），清理系统脏数据。
- **资源清理**：监控不活跃的内核 (Kernel) 并进行后台回收。

## 3. 架构级扩展管理 (Architectural Extensions)
- **MCP (Model Context Protocol) 治理**：
    - 管理 MCP 服务器配置与模板。
    - 配置工具路由 (Tool Routes)，控制 AI Agent 的能力边界。
    - 实时监控外部工具服务器的连通性。

## 4. 深度统计与性能监控 (Metrics & Monitoring)
- **AI RAG 指标中心**：
    - 监控检索维度、向量索引大小、检索命中率及重排序 (Reranker) 性能。
    - 统计 AI 响应的引用有效性 (Citation Valid Rate)。
- **文档渲染管线监控**：
    - 查看 PDF 解析各个阶段的状态、耗时及失败原因。
- **资源消耗审计**：
    - 详细的 Token 消耗统计，分析各功能模块的 AI 成本。

## 5. 行政与安全审计 (Audit & Compliance)
- **全方位审计日志**：记录谁在什么时间通过什么方式修改了系统核心配置或用户信息。
- **明星导师仪表盘**：分析导师的影响力、带生规模及其小组的学术活跃度。
