# 智能分块功能更新总结

本次更新为科研助手平台引入了全新的**智能分块（Smart Chunking）**系统，旨在提高文档处理的灵活性和检索的准确性。

## 新增功能点

### 1. 多样化分块策略
- **固定分块 (Fixed)**: 经典的按字符数切分，适用于简单场景。
- **语义分块 (Semantic)**: 利用阿里云 `text-embedding-v2` 嵌入模型计算语义相似度，在语义发生转折的地方进行切分，确保每一块内容的连贯性。
- **层级分块 (Hierarchical)**: 将文档划分为段落、章节、整个文档三个层级，支持不同粒度的信息检索。
- **学术论文专用 (Academic)**: 专门针对学术论文结构（摘要、引言、方法、结论等）进行识别和优化切分。
- **混合策略 (Hybrid)**: 智能检测文档类型（如是否为论文）并自动选择最佳分块组合，是系统推荐的默认方式。

### 2. 增强型元数据管理
- 新的分块模型支持记录：**层级信息**、**章节类型**（Abstract/Methodology等）、**章节标题**、**引用上下文**以及**语义相关性得分**。

### 3. API 扩展
- **预设配置 (Presets)**: 提供 `default`, `fast`, `precise`, `academic`, `deep` 等一键式配置。
- **预览功能 (Preview)**: 用户在应用分块策略前，可以在界面上粘贴文本并即时查看分块效果。
- **文档分析 (Analyze)**: 自动分析上传文档的结构并推荐最佳策略。
- **策略对比 (Compare)**: 支持并排比较不同策略的块数量、平均长度及内容示例。

### 4. 前端界面更新
- 在知识库页面增加了智能分块的操作入口和配置面板。
- 提供了交互式的策略选择和参数微调界面。

## 技术实现
- **后端**: 核心逻辑位于 `SmartChunkingService` 类，集成了语义边界检测和学术结构分析。
- **数据库**: 通过 Alembic 迁移（版本 `007`）新增了存储层级关系和增强元数据的字段。
- **工具链**: 提供了 `test_smart_chunking_docker.sh` 脚本用于验证 Docker 环境下的功能集成。
