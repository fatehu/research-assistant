# 检索单因素消融汇总

- 日期：`2026-03-30`
- 阶段：`retrieval ablation`
- 状态：`done`

## 范围

本轮已完成一次单因素消融或单因素系统 probe 的项目：

- dense baseline
- adaptive dimension
- hybrid
- rerank
- query rewrite
- contextual compression
- parent context
- adjacent context

## 汇总结论

1. **dense baseline**
   - 当前 `BAAI/bge-m3 / 1024 dim` 的 dense 底盘稳定可用
   - 后续组合消融应以这条链作为共同基线

2. **adaptive dimension**
   - `1024 > 512 > 256`
   - 低维主要保住 `Recall@10`，但会伤 `NDCG/MRR`
   - 当前更像“可接受的成本优先折中”，不是主修复项

3. **hybrid**
   - 第一轮信号偏向“改善顶部排序”
   - 对 `Recall@10` 不一定稳定增益

4. **rerank**
   - 最早的 `dense-only` 最小 smoke 上没有带来正收益
   - 但在 `backend hybrid + rerank` smoke 上，`@3/@5` 排序质量有明确提升
   - 当前更像“高质量模式增强项”，不是默认增强项
   - 冷启动和热态延迟仍然偏高

5. **query rewrite**
   - backend service 正常
   - 小样本上有正向收益信号
   - 但延迟代价高

6. **contextual compression**
   - 不适合用公开检索分数直接判断
   - `single` 稳，`batch` 不稳
   - `min_relevance=4.0` 偏严

7. **parent context**
   - 不改变排序
   - `64%` 结果能补到父级上下文

8. **adjacent context**
   - 不改变排序
   - `100%` 结果能补到相邻上下文

## 当前结论

- 检索相关因素的 **第一轮单因素消融已完成**
- 接下来可以进入 **组合消融**
- 当前不再把 `adaptive dimension` 作为优先优化对象
- 当前还不建议根据单项结果立刻改默认开关，而应先观察：
  - `hybrid + rewrite`
  - `hybrid + rerank`
  - `rewrite + rerank`
  - 以及最终主链组合的整体收益
