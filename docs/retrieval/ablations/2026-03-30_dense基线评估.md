## 问题

需要先确认当前系统的 dense retrieval 底盘是否足够稳定，作为后续 `hybrid / rerank / rewrite` 的共同基线。

## 评测口径

- 数据集：`BEIR / SciFact`
- 样本：`50 queries / 600 corpus`
- embedding：`BAAI/bge-m3 / 1024 dim`
- score：`cos_sim`
- 结果文件：
  - [metrics.json](/mnt/d/codefield/agent-platform/research-assistant/backend/eval/retrieval_beir/output/scifact/20260330-070811-baai-bge-m3-dim1024/metrics.json)

## 正式结果

- `NDCG@10 = 0.84870`
- `Recall@10 = 0.936`
- `MRR@10 = 0.825`

## 结论

- 当前 dense 底盘在公开集子集上表现稳定
- 这轮没有发现“dense 本身明显失效”的信号
- 后续 `hybrid / rerank / rewrite` 应以这条 `1024 dim dense` 作为共同对照基线
