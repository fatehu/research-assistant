## 发现与处理

1. 发现：早期脚本存在假通过
- 现象：`run-code` 出错时 CLI 仍可能返回 0
- 处理：在脚本中增加 `### Error/error:` 检测并抛错

2. 发现：保存按钮命中歧义
- 现象：`Save Settings` 与 `Save` 同时存在
- 处理：改为 `button:has(.anticon-save)` 的第二个按钮定位 MCP Save

3. 发现：空配置导致 400
- 现象：直接 Validate/Save 可能返回 400
- 处理：先执行 `Apply Template`，并将接口断言提升为必须 2xx
