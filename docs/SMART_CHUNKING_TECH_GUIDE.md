# 智能分块（Smart Chunking）技术实现详解

本文档旨在深入分析本项目中“智能分块”功能的架构设计与核心技术实现，帮助开发者了解如何利用语义分析、层级结构和文档识别技术提升 RAG（检索增强生成）系统的性能。

## 1. 整体架构设计

智能分块功能采用了**外观模式（Facade Pattern）**和**策略模式（Strategy Pattern）**。

- **Service 层 (`SmartChunkingService`)**: 统一入口，负责协调各个专门的分块器，并提供同步/异步接口。
- **专门分块器**:
    - `SemanticChunker`: 负责语义边界探测。
    - `HierarchicalChunker`: 负责构建父子级关联。
    - `AcademicStructureDetector`: 基础工具类，通过正则识别学术文档结构。
- **API 层 (`chunking.py`)**: 将后端能力暴露为 RESTful 接口，支持预览、分析和策略比较。

## 2. 核心分块策略实现

### 2.1 语义分块 (Semantic Chunking)
**核心逻辑**：利用向量嵌入的相似度来寻找“话题转换点”。

- **滑动窗口算法**：
    1. 将文档拆分为句子。
    2. 使用滑动窗口（默认大小为 5）将句子分组。
    3. 调用 `embedding_service` 获取每组句子的向量。
    4. 计算相邻两组向量的**余弦相似度**。
    5. **阈值触发**：当相似度低于设定值（如 0.7）时，认为发生了语义偏移，在此处切断并开启新块。

### 2.2 层级分块 (Hierarchical Chunking)
**核心逻辑**：模仿人类阅读习惯，建立细粒度与粗粒度的关联。

- **多层级表示**：
    - `Paragraph` (段落级): 基础的信息单元。
    - `Section` (章节级): 包含多个段落，通常是一个完整的论点。
    - `Document` (文档级): 整份文档的摘要或核心信息。
- **关系维护**：通过元数据中的 `parent_id` 和 `child_ids` 在分片之间建立树状引用。这在 RAG 中非常有用——检索到具体段落后，可以轻松扩展到其所在的整个章节（Parent），获取更完整的上下文。

### 2.3 学术结构识别 (Academic Structure)
**核心逻辑**：利用领域知识（Domain Knowledge）和正则表达式。

- **正则匹配**：内置了多语言（中/英）的学术章节模式，如 `Abstract`, `Methodology`, `Conclusion` 等。
- **智能映射**：自动识别分片所属的科研环节。例如，如果分片位于 `Methods` 章节，则标记为学术相关，并调高其权重。

## 4. 前后端交互流程

1. **预览模式**：前端将文本和配置发送到 `/preview`，后端实时返回分块结果。前端使用不同颜色的高亮或卡片列表示意。
2. **文档分析**：调用 `/analyze`。后端返回文档是否为学术论文、预估块数等。
3. **策略对比**：一次性使用多种策略分块并返回统计数据（如块大小分布、引用保留率），帮助用户选择最适合的预设（Preset）。
