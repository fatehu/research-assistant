# 论文阅读工作台 V2 阶段一+阶段二实现说明

## 1. 本轮目标
1. 完成阅读器从静态展示到“可验证、可操作、可局部修复”的主链路改造。
2. 落地阶段二入口参数（颗粒度、对比模式、引用 TL;DR 开关）并贯通前后端。
3. 修复阅读链路中的乱码提示词与用户可见错误文案，避免模型输出污染。

## 2. 后端实现
### 2.1 Composed API 兼容增强
- 文件：`backend/app/api/literature.py`
- 变更：
  - `reader/composed/stream`、`prefetch`、`node/action`、`inline-query/stream` 对新增字段改为 `getattr(payload, ...)` 兼容读取。
  - 兼容旧调用对象，避免因缺少新字段导致 SSE 首事件直接 `error`。

### 2.2 乱码修复（阅读链路重点）
- 文件：`backend/app/api/literature.py`
- 变更：
  - 修复 `LiteratureAskAgentCore.SYSTEM_PROMPT` 与 `CITATION_POLICY_PROMPT` 的乱码。
  - 修复 `paper_read` / `knowledge_search` 工具描述、提示、回退文案中的乱码。
  - 修复多处用户可见错误提示（论文不存在、问答会话不存在、评论/批注不存在等）乱码。
  - 修复文档注释与日志中的关键乱码文本，确保 UTF-8 输出可读。

### 2.3 测试修正
- 文件：`backend/tests/test_literature_reader_composed.py`
- 变更：
  - `run_react_compose_loop` 用例补齐 `theme_mode/detail_level/compare_mode` 参数。
  - SSE 事件顺序用例 payload 补齐 `theme_mode/detail_level/compare_mode/citation_tldr`。

## 3. 前端实现
### 3.1 PaperReaderPage 主链路接线
- 文件：`frontend/src/pages/literature/PaperReaderPage.tsx`
- 变更：
  - composed stream/prefetch 接入：`theme_mode`、`detail_level`、`compare_mode`、`citation_tldr`。
  - 阅读会话持久化扩展：`last_anchor` 写回
    - `theme_mode`
    - `detail_level`
    - `compare_mode`
    - `citation_tldr`
    - `compose_quality_target`
  - 恢复逻辑扩展：进入页面时恢复上述模式参数。

### 3.2 节点级动作（阶段一核心）
- 文件：`frontend/src/pages/literature/PaperReaderPage.tsx`
- 变更：
  - 新增节点动作处理：`修复(regenerate)` / `降级(degrade)`。
  - 调用 `actionReaderComposedNode` 后仅局部替换节点（不重刷整页）。
  - overlay 结果在前端 compose state 中即时合并。

### 3.3 内联问答（阶段一核心）
- 文件：`frontend/src/pages/literature/PaperReaderPage.tsx`
- 变更：
  - 新增 `streamReaderComposedInlineQuery` 接线。
  - 支持段间 `InlineQuerySlot` 提问后原地插入 `AnswerCard`。
  - 失败时使用 token 聚合结果做兜底答案卡，避免用户操作无反馈。

### 3.4 PiP 证据预览（阶段一核心）
- 文件：`frontend/src/pages/literature/PaperReaderPage.tsx`
- 变更：
  - 新增锚点预览状态机：hover 预览、click 钉住、关闭。
  - 支持从锚点拉取原文片段文本（当前页/跨页）。
  - “定位到证据”可联动页码跳转与 PDF 对照。

### 3.5 拖拽到右侧工作区（阶段一核心）
- 文件：`frontend/src/pages/literature/PaperReaderPage.tsx`
- 变更：
  - 批注输入框支持 `application/x-reader-component+json` 与 `text/markdown` drop。
  - 组件 Markdown 可按光标位置插入批注草稿。

### 3.6 Composed 头部控制（阶段二入口）
- 文件：`frontend/src/pages/literature/PaperReaderPage.tsx`
- 变更：
  - 增加主题切换（浅色/深色）。
  - 增加颗粒度切换（简洁/标准/深入）。
  - 增加 `对比模式` 与 `引用TL;DR` 开关。

## 4. 其他
- 前端渲染器已通过 `readerComponents/index.tsx` 的动作化组件体系（修复/降级/定位证据/拖拽/内联提问）完成接线。
- 本轮未改动 OCR 路径，仍保持“扫描型 PDF 优先回退 PDF 阅读”。

## 5. 风险与后续
1. `backend/app/api/literature.py` 仍存在少量历史乱码注释（非用户可见主链路），建议下一轮做全文件清扫。
2. PiP 当前为“证据文本预览”，后续可继续升级为 PDF 局部截图高亮。
3. 可在下一轮接入阶段二的 `QualityPanel` 自动修复建议按钮与 `CompareInsightsCard` 深化联动。
