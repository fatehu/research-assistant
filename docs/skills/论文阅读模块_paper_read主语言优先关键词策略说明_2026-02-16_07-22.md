# 论文阅读模块_paper_read 主语言优先关键词策略说明

- 时间：2026-02-16 07:22
- 目标：调用 `paper_read` 时优先使用与论文主语言一致的检索词，提升跨语言论文命中稳定性。

## 实现内容
1. 主语言检测
- 文件：`backend/app/api/literature.py`
- 新增 `_detect_text_language(text)`：按中英文字符占比判断 `zh/en/mixed/unknown`。
- 在 `LiteratureDirectPaperReadTool` 中新增 `_detect_paper_primary_language(pages)`：基于论文前 3 页文本样本判断主语言。

2. 关键词扩展与优先级
- 文件：`backend/app/api/literature.py`
- `_extract_query_terms` 新增参数 `paper_primary_language`。
- 新增英转中映射 `_PAPER_READ_EN_TO_CN_TERMS`，与既有中转英映射互补。
- 关键词分层：
  - `primary_terms`：与论文主语言一致
  - `secondary_terms`：跨语言兜底
- 回退章节词按主语言优先：
  - 英文论文优先 `abstract/introduction/method/...`
  - 中文论文优先 `摘要/引言/方法/...`

3. 运行时结果透出
- `paper_read` 返回数据新增 `paper_primary_language`，便于调试与日志观察。

4. 提示词约束同步
- `LiteratureAskAgentCore` 决策原则更新：`paper_read.query` 优先使用论文主语言关键词。

## 预期效果
- 中文提问 + 英文论文：优先命中英文术语，不再被中文模板词拖累。
- 英文提问 + 中文论文：优先补足中文章节词，提高中文论文定位命中。
