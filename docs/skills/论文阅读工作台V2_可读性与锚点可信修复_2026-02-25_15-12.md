# 论文阅读工作台 V2 可读性与锚点可信修复

## 背景与目标
- 问题1：浅色模式下 Composed Reader 多处卡片对比度不足，文本难以阅读。
- 问题2：内联问答经常出现“无法从上下文回答”，未关联段落证据。
- 问题3：质量分偏低，主要扣分来自锚点范围非法与标题完整性判定偏严。
- 问题4：首屏结构中标题行存在拆分，导致格式保真不足。

## 本次实现

### 1. 前端可读性修复（主题隔离）
- 新增样式文件：`frontend/src/pages/literature/composedReader.css`。
- 为 Composed Reader 主面板和证据 PiP 面板增加作用域类：
  - `.reader-composed-surface`
  - `.reader-composed-preview`
- 通过 CSS 变量覆盖全局 `.ant-card !important` 样式，统一卡片背景、边框、文本颜色。
- 关闭 Composed 区域内卡片 hover 位移，避免阅读抖动。
- Popover 增加独立主题类 `.reader-composed-popover`，保证 TL;DR 在浅色/深色均可读。

### 2. 前端组件渲染增强（readerComponents）
- `ActionBar` 非悬停透明度从极低提升为可读态（浅色 0.9 / 深色 0.62）。
- `ActionBar` 按钮颜色改为主题 token 驱动。
- 正文段落与列表统一使用样式 token（字体、字号、行高、颜色）。
- `SectionHeading` 使用主题标题色与标题字体。
- `CitationLinks` 的 Popover 与链接胶囊背景改为主题感知。
- `CompareInsightsCard`、`PdfSnippetCard` 改为使用 `baseCardStyle(ctx)`，避免样式失配。

### 3. 后端锚点合法化与标题修复（compose service）
- `COMPOSE_AGENT_PROMPT_VERSION` 升级到 `reader_compose_prompt_v2`，用于缓存签名升级，避免旧缓存污染。
- 新增 `_normalize_anchor_ref`：统一修复 page/start/end 合法性。
- 新增 `_sanitize_ui_plan_anchors`：每轮评分前清洗组件树锚点，降低 `anchors_valid=false` 误罚。
- 新增 `_normalize_blocks_for_render`：构建前预处理块文本并合并被拆开的连续标题行。
- 新增 `_should_merge_heading_lines`：对标题续行（如 `for ...` / `language models`）执行合并。
- 增强 `_repair_heading_text` 与 `_repair_text_artifacts`，补充常见断词/连词修复。
- `_check_title_integrity` 调整：跳过泛化标题（如 `RESEARCH ARTICLE`），并允许用正文标题节点辅助判定。

### 4. 内联问答上下文增强（compose service）
- `InlineQuerySlot` 支持通过 `target_node_ref` 回溯目标正文节点。
- 问答上下文改为：当前章节 + 当前节点 + 邻近节点 + 证据锚点引用。
- 当节点无锚点时，自动回退邻近正文锚点，保证问答可追溯。
- 回答提示词固定两句结构（结论/证据），减少空泛回复。
