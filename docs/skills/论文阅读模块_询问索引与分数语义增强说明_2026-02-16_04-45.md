# 论文阅读模块：询问索引与分数语义增强说明（2026-02-16 04:45）

## 1. 目标
- 修复“回答中的 `[n]` 与右侧引用来源无法对齐”的可用性问题。
- 修复“兜底检索分数显示为 `0` 容易误导为效果差”的语义问题。
- 修复“直接进入文本模式偶发无可提取文本”的初始化问题。

## 2. 本阶段改动范围（白名单）
- `backend/app/api/literature.py`
- `backend/app/schemas/literature.py`
- `frontend/src/services/api.ts`
- `frontend/src/pages/literature/PaperReaderPage.tsx`

## 3. 关键实现
### 3.1 后端询问来源结构增强
- 在 `LiteratureAskSource` 中新增 `idx`（引用序号）与 `score_source`（`fts|fallback`）。
- 将 `score` 从必填 `float` 调整为可空，避免 fallback 强行返回 `0`。
- `public_sources` 向前端透传 `idx`、`score_source`。

### 3.2 前端引用映射与可点击跳转
- 询问回答区新增 `[n]` 解析渲染逻辑：
  - 自动识别回答文本中的 `[1] [2] ...`。
  - 与右侧来源 `idx` 建立映射。
  - 点击 `[n]` 直接触发已有 `jumpToSource`。
- 右侧来源列表展示统一格式 `[来源n] 文档名`，与回答引用编号一致。

### 3.3 分数语义改进
- 来源来自 fallback 检索时：
  - 不再显示 `分数: 0`。
  - 改为 `分数: 无（回退检索）`，降低误读风险。

### 3.4 文本模式初始化增强
- 新增 `pdfjs.getDocument(pdfSource)` 预加载流程，独立于 PDF 可视渲染。
- 文本提取不再依赖“先切到 PDF 模式触发 onLoadSuccess”。

## 4. 效果感知
- 回答中的 `[n]` 可以与右侧来源一一对应并可点击跳转。
- 兜底检索来源不会再被误解为“低分命中”。
- 文本模式首次进入时更稳定，可直接提取当前页文本。

## 5. 回滚路径
- 如需回滚，仅撤销上述四个文件对应改动，不影响数据库结构迁移。
