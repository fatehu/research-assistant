# CodeLab 推理面板流畅度优化说明（2026-02-16 13:41）

## 1. 目标
- 解决 CodeLab 中“推理面板相较 AI 对话页不流畅”的体验问题。
- 不改变业务行为，仅做渲染与交互层优化。

## 2. 改造范围
- `frontend/src/components/NotebookAgentPanel.tsx`
- `frontend/src/pages/chat/components/HistoryReActPanel.tsx`

## 3. 关键优化
1. 流式滚动优化
- 将消息新增与流式输出分开处理：
  - 消息新增时使用 `smooth` 滚动。
  - 流式 token 更新时使用 `auto` 滚动，避免每个 token 触发平滑动画造成卡顿。

2. 历史消息渲染优化
- 对 `renderMessageContent` 使用 `useCallback`。
- 对历史消息列表使用 `useMemo` 缓存，避免流式阶段反复重渲染整段历史消息 Markdown。

3. 推理面板可见性优化
- `HistoryReActPanel` 增加 `defaultExpanded` 参数。
- CodeLab 流式推理面板默认展开，减少“需要点开才能看到过程”的感知延迟。

## 4. 风险与兼容
- 不涉及 API 结构变更。
- 仅前端渲染逻辑调整，历史消息与事件消费保持兼容。

## 5. 可感知效果
- 推理步骤更新更平稳。
- 长历史对话下，流式输出期间卡顿和抖动降低。
- 推理内容默认可见，更接近主聊天页体验。
