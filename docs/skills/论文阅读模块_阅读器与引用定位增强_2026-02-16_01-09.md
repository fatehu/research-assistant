# 论文阅读模块阅读器与引用定位增强（阶段说明）

- 时间：2026-02-16 01:09
- 阶段目标：修复“引用页码不可用/不可信”与“阅读器体验弱”的核心问题，补强问答引用定位与阅读可用性。

## 1. 本阶段实现

1. 后端引用来源元数据增强
- 文件：`backend/app/api/literature.py`
- 在问答来源中新增并返回：
- `page_source`（`metadata|estimated|unknown`）
- `section_title`
- `section_type`
- 页码策略升级：
- 优先读取 metadata 的真实页码字段（含嵌套结构）
- 若无页码但有 `position_ratio`，则结合 PDF 总页数估算页码
- PDF 页数读取加入内存 TTL 缓存，避免重复 IO

2. 阅读器文件流接口
- 文件：`backend/app/api/literature.py`
- 新增：`GET /api/v1/literature/papers/{paper_id}/pdf`
- 行为：优先返回本地 PDF；本地缺失且有 `pdf_url` 时自动下载后再返回。
- 作用：前端 PDF.js 阅读器可稳定使用统一接口读取 PDF。

3. 前端阅读工作台升级为真阅读器
- 文件：`frontend/src/pages/literature/PaperReaderPage.tsx`
- 从 `iframe` 升级到 PDF.js（`react-pdf`）：
- 支持分页、上下页、缩放、适宽、文本层渲染
- 增加“文本模式”（当前页文本提取阅读）
- 引用来源支持“点击跳转页码”
- 引用卡片显示“章节定位 + 页码来源（估算/精确）”

4. 前端接口类型同步
- 文件：`frontend/src/services/api.ts`
- `LiteratureAskSource` 增加 `page_source/section_title/section_type`
- 新增 `getPaperPdfBlob` 供阅读器加载 PDF 文件流

5. 依赖补充
- 文件：`frontend/package.json`
- 新增：
- `react-pdf`
- `pdfjs-dist`

## 2. 用户可感知变化

1. 右侧“引用来源”不再只有无效页码，可同时显示章节定位，且页码标注“估算/精确”。
2. 点击引用可直接跳转阅读页。
3. 左侧阅读区支持可控缩放、适宽、文本层选择与“文本模式”阅读，解决字号过小与阅读负担问题。

## 3. 风险与后续

1. 对仅有 `position_ratio` 的旧数据，页码为“估算值”，已在 UI 显式标注；后续可在入库阶段补充真实页码元数据提升准确度。
2. 前端容器使用命名卷 `frontend_node_modules`，新增依赖后需在容器内执行一次 `npm install` 或重建卷。
