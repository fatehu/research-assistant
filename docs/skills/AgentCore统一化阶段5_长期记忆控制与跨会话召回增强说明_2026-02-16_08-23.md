# AgentCore统一化阶段5：长期记忆控制与跨会话召回增强说明（2026-02-16 08:23）

## 1. 本阶段目标
- 新增用户可控的长期记忆设置与清理接口。
- 将记忆召回从“仅同 scope 严格命中”升级为“用户级跨会话 + channel 隔离 + scope 加权”。
- 补齐会话摘要读取，增强多轮上下文连续性。

## 2. 改动文件白名单
- `backend/app/api/codelab.py`
- `backend/app/services/agent_runtime_service.py`
- `backend/app/services/react_agent.py`
- `backend/app/config.py`
- `.env.example`

## 3. 公共接口新增
- `GET /api/v1/codelab/agent/memory/settings`
- `PUT /api/v1/codelab/agent/memory/settings`
- `DELETE /api/v1/codelab/agent/memory`

## 4. 使用技术与做法
- 双门控：系统开关 `AGENT_LONGTERM_MEMORY_ENABLED` + 用户设置 `preferences.agent_memory.enabled`。
- 记忆召回：按 `user_id + channel` 检索，命中当前 scope 时加权，保留 recency/importance 评分。
- 生命周期治理：新增 retention 天数与每用户每 channel 条目上限，写入时自动清理。
- 上下文增强：Agent 运行前读取 `ConversationSummary`，并与召回记忆共同注入系统上下文。

## 5. 达成效果
- 长期记忆默认关闭（安全默认值），可按用户开启。
- 召回不再被单一会话硬隔离，跨会话命中能力更好。
- 提供显式清理入口，便于用户主动删除记忆。

## 6. 风险与回滚
- 召回范围扩大会提高候选计算开销，已通过 `scan_limit` 与 `top_k` 限制。
- 若出现召回噪声，可下调 `AGENT_MEMORY_SCOPE_MATCH_BOOST` 或回退为严格 scope 模式。
