# 论文阅读 Read 页图来源统一说明

时间：2026-03-13 17:50

## 背景

`/read` 当前存在两条页图来源链路：

1. AI prompt 图
   - 给 `single_agent_v2` / `layout_uid_v1` 的模型调用使用
2. `page_grounding_v1.page_image`
   - 给 grounding / fallback / 内部页图引用使用

这两条链路此前没有完全统一：

- 有的地方优先使用本地 PDF render asset
- 有的地方仍然依赖 DocMind 的临时 OSS URL

当 DocMind URL 过期或返回 `403 Forbidden` 时，会导致：

- live 页图本地化失败
- AI 分组 / fallback 继续退化
- 同一页不同环节吃到不同来源的图

## 目标

统一 `/read` 的页图资产来源：

- AI prompt 图 和 grounding/page_image 都优先使用同一张本地 PDF render asset
- 只有在本地 render asset 不可用时，才回退到 DocMind URL 的本地化下载

## 重要边界

只统一：

- `page_image.url`
- `page_image.path`
- `page_image.source`

不改变：

- `page_image.width`
- `page_image.height`

原因：

- 几何真值仍然来自 DocMind block/layout 坐标
- 若把 `width/height` 直接切到 PDF render asset 尺寸，容易再次引入高光偏移

## 实施策略

新增共享 helper，优先级如下：

1. 现有本地 page render asset
2. 通过本地 PDF 生成 page render asset
3. 仅在以上都不可用时，尝试本地化 DocMind 页图 URL

`single_agent_v2` 和 `page_grounding_v1` 统一使用这条 helper。

## 实际落地

本轮实际实现分成两步：

1. 新增 `_resolve_reader_page_image_asset(...)`
   - 优先复用现有本地 `page_render_asset`
   - 本地 PDF 可用时，直接生成 `page_render_asset`
   - 仅在以上都不可用时，才回退到 DocMind URL 本地化下载

2. 将 helper 接入两条真实入口
   - `single_agent_v2` prompt 图路径
   - `layout_uid_v1` 主分组链路使用的 `page_grounding_v1.page_image`

这一步之后，`layout_uid_v1` 不再在 step1 前直接吃 DocMind 临时 URL，而是优先吃本地 `/api/v1/literature/reader/page-assets/{paper_id}/{page}`。

## 运行态补充说明

排查过程中确认了一个容器层问题：

- `backend/requirements.txt` 已声明 `dashscope==1.24.2`
- 但当前运行中的 `research_backend` 容器里实际没有安装该 SDK
- 导致 `_invoke_single_agent_model(...)` 无法走 DashScope 本地 `file://` 图片输入
- 于是退回兼容模式 `image_url`，把 `http://localhost:8888/...` 发给阿里云，触发 `The provided URL does not appear to be valid`

本轮已在运行容器中补装 `dashscope==1.24.2`，并验证 `DashScopeMultimodalService.is_available() == True`。

## 当前结果

对 `paper 85 / page 8 / kb 84` 的 fresh rebuild 已确认：

- `engine_version = reader_compose_v14`
- `page_grounding_v1.page_image.source = page_render_asset`
- `page_grounding_v1.page_image.path = /app/uploads/reader_page_assets/85/page_8.jpg`
- `page_grounding_v1.page_image.url = http://localhost:8888/api/v1/literature/reader/page-assets/85/8`
- DashScope 多模态调用成功完成，日志里出现：
  - `multimodal call finished model=qwen3.5-plus ... images=1`

这说明：

- 页图来源统一已经真实生效
- AI prompt 图和 grounding/page_image 已对齐到同一张本地 render asset
- page 8 当前 remaining 问题已经不再是“图片没送进去”

## 回退方式

若本轮统一导致新的页图问题：

1. 回退本次提交
2. 恢复两条旧链路各自处理
3. 保留几何尺寸逻辑不变
