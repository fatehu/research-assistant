# 论文阅读模块_阅读位置自动保存改造说明

- 时间：2026-02-16 07:16
- 目标：将阅读位置从“手动点击保存”改为“翻页/缩放等变化自动保存”，避免用户遗漏。

## 改造内容
1. 自动保存策略
- 文件：`frontend/src/pages/literature/PaperReaderPage.tsx`
- 新增防抖自动保存 `useEffect`（650ms）：监听 `readPage/zoomPercent/selectedKbId/fitWidth` 变化后自动调用 `updateReaderSession`。
- 保存载荷保持与后端 `ReaderSessionUpdate` 一致：`page/zoom/scroll_y/selected_kb_id/last_anchor.fit_width`。

2. 防覆盖保护
- 增加 `readerSessionHydratedRef`：仅在首轮数据加载完成后才允许自动保存。
- 增加 `lastSavedReaderSignatureRef`：避免重复提交同一状态，减少无效请求。

3. UI 调整
- 移除“保存位置”按钮。
- 工具条改为 `自动保存` 标签，明确当前行为。

## 结果
- 翻页、缩放、切换适宽状态后会自动记住阅读位置。
- 保留本地缓存机制，同时增加后端会话持久化的自动同步。
