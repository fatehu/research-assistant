# 论文阅读器 AI 组件编排视图与乱码修复实现说明（2026-02-25 02:05）

## 1. 目标
- 将论文阅读页从“模板化文本模式”升级到“AI 组件编排视图（Composed Reader）”。
- 保留后端失败时的本地结构化文本降级链路。
- 修复本轮开发中出现的乱码与编码使用不规范问题。

## 2. 本次功能实现

### 2.1 后端
- 新增 `backend/app/services/literature_reader_compose_service.py`：
  - 页级缓存读取与构建：`build_or_get_composed_payload`
  - ReAct 迭代：`run_react_compose_loop`
  - 计划校验：`validate_ui_plan`
  - 质量评分：`score_ui_plan`
  - 资源聚合策略：`collect_assets_with_policy`
  - 预读：`queue_prefetch` / `prefetch_pages`
- 新增/扩展 schema：`backend/app/schemas/literature.py`
  - `ReaderComposeRequest`
  - `ReaderUIPlan`
  - `ReaderComponentNode`
  - `ReaderComposeQualityReport`
  - `ReaderComposePayload`
  - `ReaderComposePrefetchRequest/Response`
- 新增 API：`backend/app/api/literature.py`
  - `POST /api/v1/literature/papers/{paper_id}/reader/composed/stream`
  - `POST /api/v1/literature/papers/{paper_id}/reader/composed/prefetch`
  - SSE 事件：`start -> plan_draft -> plan_patch* -> assets -> quality -> done -> error`

### 2.2 前端
- 新增组件注册表：`frontend/src/pages/literature/readerComponents/index.tsx`
  - 支持白名单组件类型渲染：`PaperHeaderCard`、`SectionHeading`、`ParagraphProse`、`CitationLinks` 等。
  - 未知组件统一安全降级提示。
- 扩展 API SDK：`frontend/src/services/api.ts`
  - `streamReaderComposed`
  - `prefetchReaderComposed`
  - 新增 composed 类型定义。
- 阅读页接入 composed 流：`frontend/src/pages/literature/PaperReaderPage.tsx`
  - 文本模式下优先走 `composed stream`。
  - 支持 `plan_draft/plan_patch` 流式更新组件树。
  - 支持“重新生成（regenerate）”。
  - 支持邻页预读：`[p-1, p+1, p+2]`。
  - 无可用 `ui_plan` 时，自动降级到本地结构化文本展示。

## 3. 乱码处理与编码规范落地
- 本轮执行统一 UTF-8 读取/写入：
  - 读取：`Get-Content -Encoding utf8`
  - 写入：`Set-Content -Encoding utf8`
- 终端执行前设置代码页：`chcp 65001`
- 修复了本轮新增链路中的乱码文案与破损字符串。
- 说明：仓库历史文件中仍有少量旧乱码（非本次主链路），后续可独立开“纯文本治理”任务逐步清理。
