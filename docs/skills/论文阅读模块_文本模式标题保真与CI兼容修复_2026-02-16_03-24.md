# 论文阅读模块：文本模式标题保真与 CI 兼容修复（2026-02-16 03:24）

## 1. 目标
- 修复文本模式“标题丢失/吞并进正文”的排版问题。
- 修复 PR CI 的 `api-smoke` 在无 GPU Runner 上失败问题。

## 2. 本阶段改造

### 2.1 文本模式学术排版保真
- 文件：`frontend/src/pages/literature/PaperReaderPage.tsx`
- 新增 `extractAcademicPageText`：基于 PDF.js 文本项坐标重建“行”，保留换行与段落间距。
- 重写 `buildAcademicTextBlocks`：按行解析并保留章节标题，不再先全量压缩空白。
- 标题样式改造：按编号层级（如 `2`、`2.1`）设置不同字号，保留原始大小写。
- 保留学术阅读风格：衬线字体、段落缩进、可单双栏阅读。

### 2.2 CI 无 GPU 兼容
- 文件：
  - `.github/docker-compose.ci.yml`
  - `.github/workflows/pr-api-smoke.yml`
  - `.github/workflows/nightly-e2e-full.yml`
- 采用 compose 覆盖文件并使用 `!reset` 去除 `backend.gpus`。
- 在 CI workflow 中统一使用：
  - `docker compose -f docker-compose.yml -f .github/docker-compose.ci.yml ...`
- 本地主 compose 保持 GPU 能力（`DOCKER_BACKEND_GPUS`）不变。

## 3. 可感知效果
- 文本模式可稳定显示章节标题（如 `2 Related Work`, `2.1 ...`）。
- 标题不再被拼接吞并为正文片段。
- PR `api-smoke` 不再因无 GPU 环境直接失败。
