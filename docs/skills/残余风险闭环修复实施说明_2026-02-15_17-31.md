# 残余风险闭环修复实施说明

- 时间：2026-02-15 17:31
- 分支：`feature/acceptance-risk-closure-20260215`
- 目标：按验收闭环计划收敛安全、API 版本化、限流、CodeLab 沙箱化、测试门禁化与大文件拆分风险。

## 本轮改造范围

1. 安全与配置硬化（P0）
- `backend/app/config.py`
  - 增加 `APP_ENV` 与 `model_validator`。
  - 在 `staging/production` 下强制校验 `SECRET_KEY`、`DATABASE_URL` 与 `CODELAB_RUNNER_TOKEN`。
  - 新增 API 限流配置项与 CodeLab Runner 配置项。
- `docker-compose.yml`
  - 移除 `POSTGRES_PASSWORD`、`DATABASE_URL`、`SECRET_KEY` 弱默认回退。
  - 新增 `APP_ENV`、限流配置透传、runner 配置透传。
- `.env.example`
  - 弱默认替换为安全占位符。
  - 补充限流与 runner 必要环境变量。

2. API 版本化 + 限流（P1）
- `backend/app/main.py`
  - 所有对外接口切换到 `/api/v1/*`。
  - 接入限流依赖并按路由分组设置阈值（auth/chat/knowledge/codelab）。
  - 新增响应头注入中间件（`X-RateLimit-*`）。
- `backend/app/core/rate_limit.py`
  - 新增 Redis 优先、内存回退的限流实现。
  - 超限统一返回 429 与 `Retry-After`。
- 客户端与脚本同步迁移到 `/api/v1`
  - `frontend/src/services/api.ts`
  - `frontend/src/stores/roleStore.ts`
  - `frontend/src/stores/chatStore.ts`
  - `frontend/src/pages/*` 中直接调用 API 的页面
  - `acceptance_tests.ps1`
  - `e2e/*.ps1`

3. CodeLab 独立 runner（P1-P2）
- 新增 runner 服务端：
  - `backend/app/sandbox_runner/main.py`
  - `backend/app/sandbox_runner/local_executor.py`（复用原本地执行器逻辑）
- `backend/app/services/codelab_executor.py`
  - 改为 runner HTTP client。
  - 支持 `CODELAB_RUNNER_ENABLED=false` 本地开发/测试模式。
  - runner 不可达抛 `RunnerUnavailableError`。
- `backend/app/api/codelab.py`
  - 对 runner 不可用统一返回 503（`sandbox_runner_unavailable`）。
- `docker-compose.yml`
  - 新增 `codelab-runner` 服务，backend 通过内部网络访问。

4. 关键链路异常治理与门禁（P2）
- 新增统一错误模型与全局处理入口：
  - `backend/app/core/errors.py`
  - `backend/app/core/error_handlers.py`
- 新增 broad catch 增量守卫：
  - `backend/checks/check_no_new_broad_excepts.py`
- 当前 broad catch 总数由 143 降到 128（services+api）。

5. 大文件拆分（P2）
- `backend/app/services/agent_tools.py` 主体迁移至：
  - `backend/app/services/agent_tools_impl/registry.py`
- `backend/app/services/notebook_tools.py` 主体迁移至：
  - `backend/app/services/notebook_tools_impl/tools.py`
- 兼容导入：
  - 原入口文件保留为 shim，并通过 `sys.modules` 转发，确保 monkeypatch 与运行时行为一致。

6. CI 落地（P2）
- 新增：
  - `.github/workflows/pr-api-smoke.yml`
  - `.github/workflows/nightly-e2e-full.yml`
- PR 运行 API 冒烟 + broad catch 守卫；夜间运行 API+UI 全量。

## 关键说明

1. 本轮 API 路由不保留旧 `/api/*`，按开发期策略直接切换 `/api/v1/*`。
2. CodeLab runner 模式下，不做静默回退；runner 不可用时后端返回 503。
3. 为兼容现有测试，`CODELAB_RUNNER_ENABLED=false` 时仍可使用本地执行器。
