# 论文阅读模块：文本模式直开空态与排版稳定性修复（2026-02-16 03:37）

## 1. 阶段目标
- 修复“未先显示 PDF 就切到文本模式时，出现 `当前页暂无可提取文本`”的问题。
- 修复双栏论文文本抽取顺序错误导致的标题/正文错位、拼接问题。
- 收敛文本模式排版，避免异常放大导致阅读层级失真。

## 2. 本阶段改造

### 2.1 文本模式直开空态修复（核心）
- 文件：`frontend/src/pages/literature/PaperReaderPage.tsx`
- 改造点：`PdfDocument` 在 `pdfSource` 可用时始终挂载。
  - 即使当前处于文本模式，也保持 PDF 文档对象可初始化（仅隐藏可视渲染区域）。
  - 解决此前“文本模式下未挂载 `PdfDocument` -> `pdfDoc` 永远为空 -> 文本抽取不触发”的时序问题。

### 2.2 双栏与段落抽取增强
- 文件：`frontend/src/pages/literature/PaperReaderPage.tsx`
- 新增能力：
  - 基于 PDF item 的 `x/y/width/height` 进行行聚合。
  - 双栏页自动检测并按阅读顺序重排（左栏 -> 右栏，保留页首宽行）。
  - 列切换与大行距处插入段落空行，减少跨列粘连。
  - 对压缩编号行（如 `1. ... 2. ...`）做拆分，提升可读性。

### 2.3 文本抽取回退策略
- 文件：`frontend/src/pages/literature/PaperReaderPage.tsx`
- 若坐标抽取结果为空，则退回为 `textContent.items` 拼接文本，避免误判“无文本可提取”。

### 2.4 文本模式样式收敛
- 文件：`frontend/src/pages/literature/PaperReaderPage.tsx`
- 调整：
  - 标题层级字号改为中等范围（避免过度夸张）。
  - 去除首字放大效果，避免正文误导成视觉标题。
  - 保留学术阅读基调（衬线字体、段落缩进、单双栏切换）。

### 2.5 CI 兼容补齐
- 文件：
  - `.github/docker-compose.ci.yml`
  - `.github/workflows/pr-api-smoke.yml`
  - `.github/workflows/nightly-e2e-full.yml`
- 改造：
  - CI 统一使用 compose 覆盖文件，禁用 `backend` 的 GPU 申请。
  - 增加 artifact 目录预创建，消除 `No files were found ...` 警告噪音。

## 3. 可感知效果
- 进入阅读工作台后，直接切文本模式不会再出现“空文本假失败”。
- 双栏论文中章节标题与正文顺序更稳定，不再频繁跨列拼接。
- 文本排版更接近学术阅读习惯，层级更克制。
- PR CI 在无 GPU Runner 下可正常起栈执行。

## 4. 风险与回滚
- 风险：文本抽取逻辑复杂度上升，边缘 PDF（极端布局）仍可能存在局部错行。
- 回滚方式：
  1. 回退 `PaperReaderPage.tsx` 的坐标重排与文本模式渲染变更。
  2. 回退 CI workflow 对 compose 覆盖文件的引用。
