# 论文阅读生成式界面重生成与结构修复优化说明（2026-02-24 19:42）

## 目标
- 解决生成式阅读中缓存过旧、样式切换无实效、词边界破碎（如 `RESEA RCH`）等问题。
- 增加用户主动控制能力：允许手动“重新生成”，并优先触发 Agent 修复。

## 本次改动
1. 后端生成链路
- `ReaderGenerativeRequest` 新增 `prefer_agent`。
- 当 `prefer_agent=true` 时，服务层强制 `force_refresh=true`，跳过缓存重建。
- 解析器版本升级为 `reader_parser_v3`，用于缓存失效与重建。
- 移除 `preview_hint` 资产输出，避免与 PDF 模式功能重叠。

2. 文本结构修复
- 增强词边界修复策略，重点处理论文页常见粘连词、碎片标题词。
- 新增“行内标题拆分”逻辑，将正文中混入的 `Introduction/Methods/...` 拆回结构化标题。
- 引入多提取候选评分（`pypdf` / `pdfplumber` / `pdfplumber words`），自动选质量更高结果。

3. 前端交互
- 生成式面板新增“重新生成”按钮：点击后 `force_refresh=true + prefer_agent=true`。
- 样式切换接入真实重拉流程，不再只是本地换皮。
- 移除“原始PDF文本（当前页）”卡片，减少界面噪声。

4. 乱码与编码治理
- 清理服务层中出现的乱码字符串，统一可读文案。
- 相关文件统一为 UTF-8 无 BOM。
- 新增中文注释，覆盖关键复杂逻辑（缓存策略、SSE分段、词边界修复、候选评分）。

## 使用说明
- 在论文阅读页切换到“生成式模式”。
- 如结果不满意，点击“重新生成”可强制重建并优先走 Agent。
- 切换风格会触发对应风格内容重拉。
