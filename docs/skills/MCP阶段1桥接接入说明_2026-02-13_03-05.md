# MCP阶段1桥接接入说明（2026-02-13 03:05）
- 记录时间：2026-02-13 03:05
- 实施阶段：MCP 引入 Phase 1（骨架与桥接）

## 1. 本次使用的技术
1. MCP Python SDK（`mcp==1.10.1`）
2. 统一注册表模式（本地 Tool + MCP Tool 并存）
3. Adapter/Bridge 模式（`MCPRemoteTool`、`mcp/bridge.py`）
4. Feature Flag 配置（`MCP_ENABLED` 等环境变量）
5. ReAct 运行前动态发现工具（`refresh_mcp_tools`）

## 2. 目的是什么
1. 在不破坏现有本地工具体系的前提下，引入 MCP 标准能力。
2. 让系统具备“可增量接入远程 MCP Server 工具”的能力。
3. 为后续 Phase 2（内部工具 MCP 化）提供稳定底座。

## 3. 怎么用（实现方式）
1. 新增 MCP 服务模块：
- `backend/app/services/mcp/config.py`
- `backend/app/services/mcp/server_manager.py`
- `backend/app/services/mcp/client.py`
- `backend/app/services/mcp/bridge.py`
- `backend/app/services/mcp/__init__.py`
2. 升级 `ToolRegistry`（`backend/app/services/agent_tools.py`）：
- 保留 `self._tools`（本地工具）
- 新增 `self._mcp_tools`（远程工具缓存）
- 新增 `refresh_mcp_tools()`、`_init_mcp_client_manager()`
- `execute()` 支持远程 MCP 调用与本地优先策略
3. ReAct 运行链路接入：
- `backend/app/services/react_agent.py` 在 `run()` 开始前调用 `refresh_mcp_tools()`
4. 工具列表接口接入：
- `backend/app/api/notebook_agent.py` 的 `/agent/tools` 查询前刷新 MCP 工具
5. 配置与部署接线：
- `backend/app/config.py` 新增 `mcp_enabled/mcp_tool_prefix/mcp_call_timeout_seconds/mcp_servers`
- `.env.example` 新增 MCP 配置样例
- `docker-compose.yml` 透传 MCP 环境变量
- `backend/requirements.txt` 新增 `mcp==1.10.1`

## 4. 做到了什么
1. 现有 ReAct 代理可在同一注册表下同时使用本地工具和 MCP 工具。
2. MCP 默认关闭（`MCP_ENABLED=false`），不影响现有生产行为。
3. 打开开关后，可通过 MCP Server 动态发现远程工具并参与提示词构建与执行。
4. 本地工具优先级保留，避免 MCP 接入影响高风险本地工具链路。

## 5. 怎么感知效果
1. 运行时日志出现：
- `[MCP] MCP client manager initialized`
2. `ToolRegistry.list_tools()` 中出现形如 `mcp.<server>.<tool>` 的工具名。
3. Agent 对话中可触发远程工具调用（执行结果进入 observation）。
4. 未配置 MCP 时，系统行为与接入前一致。

## 7. 部署方法（Docker）
1. 在 `.env` 配置（示例）：
```env
MCP_ENABLED=true
MCP_TOOL_PREFIX=mcp
MCP_CALL_TIMEOUT_SECONDS=20
MCP_SERVERS=[{"name":"fetch","transport":"stdio","command":"npx","args":["-y","@modelcontextprotocol/server-fetch"]}]
```
2. 重新构建并启动后端：
```bash
docker compose build backend
docker compose up -d backend
```
3. 验证：
```bash
docker compose logs -f backend
```
4. 预期看到：
- MCP 初始化日志
- Agent 调用时可发现 `mcp.<server>.<tool>` 工具
