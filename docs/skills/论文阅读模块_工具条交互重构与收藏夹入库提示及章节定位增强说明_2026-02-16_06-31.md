# 论文阅读模块：工具条交互重构、收藏夹入库提示与章节定位增强说明（2026-02-16 06:31）

## 1. 目标
- 重构阅读页顶部工具条，缓解控件拥挤并补齐“返回”交互。
- 在“当前收藏夹询问”场景增加入库就绪提示，明确哪些论文会参与联合回答。
- 提升引用“章节级定位”能力，从“仅提示章节名”升级为可自动定位到页和标题。

## 2. 变更白名单
- `frontend/src/pages/literature/PaperReaderPage.tsx`
- `frontend/src/services/api.ts`
- `backend/app/api/literature.py`
- `backend/app/schemas/literature.py`

## 3. 关键实现
1. 阅读区工具条重构
- Card 标题区增加“返回”按钮（历史返回，兜底回到 `/literature`）。
- 将原单行拥挤工具条拆分为两排：
  - 第一排：分页 + 关键动作（适宽/模式/保存）
  - 第二排：缩放滑杆
- 增加章节定位中状态标签。

2. 收藏夹联合回答入库提示
- 新增后端接口：
  - `GET /api/v1/literature/collections/{collection_id}/knowledge-readiness?knowledge_base_id=...`
- 返回每篇论文在当前 KB 下的状态统计（ready/processing/pending/failed/missing）。
- 前端在“询问”面板中展示：
  - 可联合回答论文数（ready/total）
  - 未就绪状态分布
  - 未就绪论文示例标题
- 若收藏夹在当前 KB 下无 ready 论文，前端提交前直接提示并阻断无效提问。

3. 章节级定位增强
- 对引用来源仅有 `section_title` 无页码时：
  - 先尝试当前页文本模式标题匹配并滚动高亮。
  - 若当前页未命中，则跨页扫描 PDF 标题（最多 80 页）并定位到最可能页。
  - 定位后自动切换文本模式并高亮对应标题。
- 增加章节名归一化、编号匹配和关键词重叠评分，提高命中精度。

## 4. 用户可感知变化
- 顶部操作区明显更松散，返回动作可用。
- 收藏夹询问前能看到“哪些论文会参与回答”。
- 章节引用支持更智能的自动跳转，不再只提示“请手动查看章节”。

## 5. 风险与后续
- 跨页章节扫描会带来额外耗时，当前已限制扫描上限以控制开销。
- 后续可将章节定位结果持久化到后端缓存，降低重复扫描成本。
