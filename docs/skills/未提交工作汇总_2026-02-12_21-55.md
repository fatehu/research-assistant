## 2. 改动范围（当前未提交）

### 后端
1. `backend/app/schemas/knowledge.py`
- 新增搜索请求字段 `use_contextual_compression`（默认 `false`），允许请求侧显式控制是否启用上下文压缩。

2. `backend/app/api/knowledge.py`
- 在调用上下文压缩服务时，传入 `use_contextual_compression=request.use_contextual_compression`。
- 目的：避免压缩逻辑仅由全局配置隐式控制，改为“全局配置 + 请求开关”双重控制。

3. `backend/app/config.py`
- 新增配置项 `sqlalchemy_echo: bool = False`。
- 目的：将 SQL 日志开关从 `debug` 解耦，避免开发调试日志过多影响定位问题。

4. `backend/app/core/database.py`
- 数据库引擎 `echo` 从 `settings.debug` 改为 `settings.sqlalchemy_echo`。

5. `docker-compose.yml`
- 新增环境变量透传：`SQLALCHEMY_ECHO=${SQLALCHEMY_ECHO:-false}`。

6. `.env.example`
- 新增示例配置：`SQLALCHEMY_ECHO=false`。

### 前端
1. `frontend/src/services/api.ts`
- 新增 `KnowledgeSearchOptions` 类型，包含：
  - `useReranker`
  - `useHybrid`
  - `useQueryRewrite`
  - `useContextualCompression`
  - `queryRewriteStrategies`
  - `timeoutMs`
- `knowledgeApi.search` 增加 `options` 参数，并把对应字段映射到后端请求体；支持请求超时配置。

2. `frontend/src/stores/knowledgeStore.ts`
- `search` 方法增加 `options?: KnowledgeSearchOptions` 并透传给 `knowledgeApi.search`。

3. `frontend/src/pages/knowledge/KnowledgePage.tsx`
- 知识库“向量搜索”弹窗高级过滤中新增显式开关：
  - Query Rewrite
  - Hybrid 检索
  - Reranker
  - Contextual Compression
  - 请求超时（45s/90s/120s）
- 搜索执行时把上述选项作为请求参数提交。
- 高级过滤状态点逻辑同步纳入上述开关/超时项。
