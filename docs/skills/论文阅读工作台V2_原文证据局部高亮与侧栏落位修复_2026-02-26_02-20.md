# 论文阅读工作台V2：原文证据局部高亮与侧栏落位修复

## 目标
1. 修复证据预览遮挡正文的问题，把“原文证据”固定放到右侧批注区下方。
2. 将证据预览从纯文本片段升级为“原始 PDF 局部渲染 + 高亮框”。
3. 提升锚点选择与匹配可靠性，避免总是取第一个锚点导致错位。
4. 清理后端 compose 服务残留乱码文案，避免继续污染前端展示。

## 本次实现
1. 前端新增锚点匹配策略：
   - 按页优先、bbox_hint 优先、quote 长度和 span 质量综合评分选择主锚点。
2. 前端新增 PDF 局部高亮渲染：
   - 优先使用 `bbox_hint` 定位；
   - 失败后回退到 quote 精确匹配、quote 模糊匹配、char-range 匹配；
   - 最终回退页级截图；
   - 输出 `match_method` 与 `match_confidence`。
3. 前端证据展示改造：
   - 删除悬浮固定层（不再覆盖正文）；
   - 在右侧“批注”工作区列表下新增“原文证据”卡片；
   - 卡片显示定位依据、置信度、局部高亮图、证据文本、跳转按钮。
4. 前端清理临时损坏文件影响：
   - 处理 `PaperReaderPage.recovered*.tmp.tsx` 导致的构建失败问题（已从编译路径移除）。
5. 后端 compose 服务乱码治理：
   - 修正文案：`复制 / 修复 / 降级 / 链接 / 复制Markdown`；
   - 修正摘要分句正则为 `[。！？!?;；]`；
   - 修复服务头部注释乱码。

## 关键文件
1. `frontend/src/pages/literature/PaperReaderPage.tsx`
2. `backend/app/services/literature_reader_compose_service.py`

## 效果感知
1. 悬停左侧带 `source_anchor_refs` 的组件时，右侧批注区下方出现“原文证据”卡片。
2. 证据卡优先展示局部高亮图（橙色高亮框），并显示定位依据与置信度。
3. 证据卡不再覆盖正文阅读区域。
4. 重新生成后端计划时，按钮文案不再出现乱码。
