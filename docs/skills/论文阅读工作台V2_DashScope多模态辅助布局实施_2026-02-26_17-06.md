# 论文阅读工作台V2：DashScope 多模态辅助布局实施说明

- 时间：2026-02-26 17:06
- 阶段：排版增强（非 OCR）
- 目标：在“可提取文本 PDF”主链路不变前提下，引入低频多模态辅助，仅做版面结构裁决，不做正文改写。

## 本阶段完成项
1. 新增多模态布局辅助服务 `reader_multimodal_layout_service.py`。
2. 增加配置开关与阈值：主模型、回退模型、超时、触发阈值、触发率上限、Prompt 版本等。
3. 扩展阅读结构字段：`zone_type`、`column_id`、`heading_prob`、`layout_confidence`。
4. 输出三通道：`main_body`、`side_context`、`figure_meta`，不再粗暴丢弃侧栏。
5. TOC 改为高置信标题驱动，低质量时隐藏并给出提示。
6. Compose 质量报告新增：`cross_column_merge_ratio`、`sidebar_recall`、`toc_quality`、`mm_assist_used` 等。
7. SSE `quality` 与 `done` 事件带回多模态指标，便于前端实时展示。
8. 前端新增 `ContextRail`，将侧栏内容与正文分离展示。

## 关键实现策略
1. 触发门控：满足低置信、标题完整性不足、侧栏泄漏、跨栏拼接偏高之一才触发。
2. 节流策略：按论文页统计触发率，超过上限时自动回退纯文本结构链路。
3. 模型策略：先 `qwen3.5-flash`，失败后单次回退 `qwen3-vl-flash`。
4. 严格协议：强制 JSON 输出并进行 schema 校验，非法输出直接回退。
5. 缓存隔离：签名加入多模态相关维度，避免旧缓存污染新模式结果。

## 用户可感知效果
1. 正文区中“侧栏元信息混入正文”的概率显著下降。
2. 双栏论文跨栏串接降低，标题识别更稳定。
3. 目录不再展示碎片标题：低质量目录自动隐藏。
4. 质量面板可看到多模态是否参与、是否触发回退及新增指标。

## 回滚与降级
1. 设置 `READER_MM_ASSIST_ENABLED=false` 可一键回退到纯文本链路。
2. 模型调用超时、失败或 JSON 非法时自动降级，不阻塞主流程。
