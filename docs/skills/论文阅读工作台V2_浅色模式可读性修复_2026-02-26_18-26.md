# 论文阅读工作台V2：浅色模式可读性修复

- 时间：2026-02-26 18:26
- 目标：修复 AI Composed Reader 在浅色模式下文字、卡片和提示信息发灰难读的问题。

## 改动摘要
1. 在阅读页引入并启用 `composedReader.css`，确保 composed 区域使用专属样式覆盖。
2. 给 composed 主容器挂载 `reader-composed-surface`，并注入主题变量（卡片背景、边框、正文色、标题色）。
3. 修复组件树渲染上下文，补传 `themeStyle`，避免组件内部颜色回退到不正确样式。
4. 增强 composed CSS 可读性规则：
   - 提高 secondary 文本不透明度
   - 补齐 Empty / Alert / Link 在 composed 区域的颜色覆盖

## 用户可感知效果
1. 浅色模式正文、标题、提示文本与卡片边框对比度明显提升。
2. 空态与警告信息不再“发灰看不清”。
3. 组件卡片在浅色模式下不再被全局暗色 `.ant-card` 误覆盖。
