# CodeLab轻量中文字体修复实施说明（2026-02-16 17:29）

## 1. 阶段目标
- 解决 CodeLab 绘图中文缺字（`Glyph ... missing from current font`）问题。
- 在保证可用的前提下，避免引入过大字体包导致构建慢或内存压力过高。

## 2. 白名单文件
- `backend/Dockerfile`
- `backend/app/sandbox_runner/local_executor.py`

## 3. 使用技术
- Docker 镜像层安装轻量中文字体：`fonts-wqy-zenhei` + `fontconfig`。
- Matplotlib 运行时字体回退链配置（优先 `WenQuanYi Zen Hei`）。
- 沙箱执行器初始化时统一设置 `axes.unicode_minus=False`，避免负号显示异常。

## 4. 具体改造
1. `backend/Dockerfile`
- 新增 `fontconfig`、`fonts-wqy-zenhei` 安装。
- 保持镜像体积和构建稳定性，不引入大体积 CJK 全量字体包。

2. `backend/app/sandbox_runner/local_executor.py`
- 在 `_capture_plot` 中增加 Matplotlib 字体回退列表配置。
- 在 `_init_namespace` 中同步字体回退配置，确保 Notebook 首次执行即生效。
- 增加 glyph 缺字告警抑制，避免噪声日志影响排障。

## 5. 达成效果
- CodeLab 执行中文绘图时不再出现缺字报错。
- 字体能力进入镜像层，容器重建后仍可复用，不依赖临时手工安装。
- 相比全量 CJK 字体方案，构建资源占用更可控。

## 6. 可感知验证点
- 在 `codelab-runner` 内执行 `fc-list` 可看到 `WenQuanYi Zen Hei`。
- 通过 `/internal/codelab/execute` 执行中文标题图代码返回成功并有图像输出。
- `codelab-runner` 日志中无新增 `Glyph ... missing` 告警。
