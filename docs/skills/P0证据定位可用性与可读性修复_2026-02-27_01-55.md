# P0证据定位可用性与可读性修复（2026-02-27 01:55）

## 目标
- 修复长段正文证据仅覆盖前半段的问题。
- 修复证据图偶发空白和 FigurePanel 空图问题。
- 修复浅色模式可读性不足。
- 修复 generative 签名 KB 限域与 inline query 模式参数一致性。

## 本次实现
1. 后端锚点分片与定位增强
- 在 `backend/app/services/literature_reader_compose_service.py` 新增长段落分片逻辑：将长 quote 切为多个锚点片段，最多 6 片。
- 新增锚点字段：`anchor_id`、`segment_index`、`segment_total`（可选，向后兼容）。
- `bbox_hint` 从单行匹配改为多行并集框，且做同栏优先与外扩处理，减少只命中上半段。

2. 质量报告指标扩展
- 在质量报告新增：`anchor_coverage_ratio`、`evidence_image_ready`。
- 在评分阶段加入对应扣分项与修复建议，帮助解释低分原因。

3. 前端证据预览链路修复
- 去除 `char_range` 仅取前 14 行的硬截断，改为按跨度动态聚合行数。
- 证据卡支持片段切换（上一片段/下一片段），可处理多锚点段落。
- 裁剪失败不再返回空图，统一回退整页裁剪并显式标注 fallback。

4. FigurePanel 空图兜底
- 在 `frontend/src/pages/literature/readerComponents/index.tsx` 为 FigurePanel 增加锚点图懒加载。
- `image_url` 为空时自动尝试锚点截图；失败显示明确占位和重试按钮，不再静默空白。

5. 浅色模式可读性修复
- 在 `frontend/src/pages/literature/composedReader.css` 补齐按钮、Select、Input、Tag 的对比度样式覆盖。
- 调整关键要点、图表解读等组件色板，提升浅色模式文本可读性。

6. 安全与一致性修复
- `backend/app/services/literature_reader_service.py` 的 `_build_source_signature` 增加 `user_id` 限域，`selected_kb_id` 仅在当前用户拥有时参与签名。
- `frontend/src/pages/literature/PaperReaderPage.tsx` 的 inline query 请求补齐 `theme_mode`、`citation_tldr`，与 compose 签名上下文一致。

- 前端保留原链路行为，新增能力为增强与兜底，不破坏现有接口。
