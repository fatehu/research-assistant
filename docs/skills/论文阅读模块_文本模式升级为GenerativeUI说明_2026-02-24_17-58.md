# 论文阅读模块_文本模式升级为GenerativeUI说明（2026-02-24 17:58）

## 1. 目标
- 将阅读页原“文本模式”升级为“生成式模式（Generative Reader）”。
- 保留原始 PDF 文本提取能力，同时增强为卡片化阅读体验。
- 在文本阅读流中补充：页面预览图、资源链接、页内注释，降低“生硬转写”感。

## 2. 范围与白名单文件
- `frontend/src/pages/literature/PaperReaderPage.tsx`

## 3. 实现内容
- 将阅读区按钮文案从“文本模式”调整为“生成式模式”。
- 新增生成式阅读面板 `renderGenerativeTextPanel()`：
  - 顶部状态条：当前页、词数、布局模式。
  - 论文元信息卡：标题、期刊/年份、作者。
  - 原始页面预览卡：基于 `pdfjs` 当前页渲染为图片（JPEG DataURL）。
  - 资源链接卡：聚合论文元数据链接 + 页内自动识别 DOI/URL。
  - 页内注释卡：同步展示当前页批注（笔记/高亮 + 更新时间）。
  - 正文卡：保留结构化段落渲染与章节跳转高亮。
  - 原始文本卡：展示当前页原始文本（可复制、可滚动）。
- 文本清洗增强：
  - 修复常见断词（`classifi- cation -> classification`）。
  - 规范中英文标点前后空格。
  - 提取行文本时统一清洗，减少排版噪声。

## 4. 可感知效果
- 阅读区在“生成式模式”下不再是纯段落堆叠，而是“内容+上下文”卡片流。
- 用户可直接在同屏查看：原页图像、可点击外链、当前页注释、结构化正文、原始文本。
- 章节定位逻辑保留，引用跳转失败时会自动切换到生成式模式继续定位。

## 5. 兼容性与风险
- 未改动后端 API 协议。
- 仅前端渲染层改造，右侧批注/评论/评分/询问工作流不受影响。
- 页面预览图按页渲染，可能带来少量前端性能开销（已限定当前页触发）。

## 6. 回滚方式
- 回滚 `frontend/src/pages/literature/PaperReaderPage.tsx` 到本次改造前版本即可。
