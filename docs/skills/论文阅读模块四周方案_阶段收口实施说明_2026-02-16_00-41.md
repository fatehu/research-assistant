## 2. 技术与实现要点

- 数据层：新增论文阅读模块相关实体，支持阅读会话、批注、评论、评分、入库关联、问答会话与消息落库。
- 接口层：新增阅读会话/批注/评论/评分汇总/入库状态/询问流式能力，评论支持 `all|same_group`，评分支持全站与同组均值。
- 询问链路：落地入库就绪校验、论文/收藏夹边界控制、来源片段返回、问答缓存（Redis 优先，内存兜底）。

## 4. 如何感知效果

- 论文详情页新增“阅读工作台”入口，进入 `/literature/:paperId/read`。
- 右侧面板可直接进行批注、评论筛选（全部/同组）、评分查看（我的/全站/同组）。
- 选择知识库后可发起“加入知识库”，并在同页查看处理状态。
- 在“询问”页签可按论文或收藏夹范围提问并接收流式回答与引用来源。

- 运行级降级：询问缓存在 Redis 不可用时自动回退到进程内缓存，不阻断主链路。
