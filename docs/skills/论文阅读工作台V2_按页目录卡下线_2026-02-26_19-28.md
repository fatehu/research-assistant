# 论文阅读工作台V2：按页目录卡下线

- 时间：2026-02-26 19:28
- 目标：移除按页阅读中的 `SectionTOC` 组件，避免“目录质量不足已隐藏”提示反复出现并占位。

## 改动说明
1. 在 composed 初始化组件树中移除 `SectionTOC` 的创建逻辑。
2. 保留 `toc_quality` 指标用于质量面板与后续观测，不影响现有评分流程兼容性。
3. 增加中文注释，说明按页目录下线原因与后续方向（跨页聚合大纲）。

## 用户可感知效果
1. 生成式阅读页不再出现“本页目录质量不足，已隐藏”卡片。
2. 页面上方可用空间增大，正文阅读流更连贯。
3. 不改变正文、侧栏、图注三通道渲染行为。
