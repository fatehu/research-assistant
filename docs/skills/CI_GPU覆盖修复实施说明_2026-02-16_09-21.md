# CI GPU 覆盖修复实施说明（2026-02-16 09:21）

## 1. 背景
- PR `#6` 合并后，`PR API Smoke` 仍失败。
- 根因：CI 机器无 NVIDIA runtime，但 `docker-compose.yml` 的 `backend` 默认声明 `gpus: all`，CI 覆盖文件未真正移除该字段。

## 2. 本次改造
- 文件：`.github/docker-compose.ci.yml`
- 改动：
  - 由 `gpus: []` 改为 `gpus: !reset []`
- 目的：
  - 使用 Compose override 的 reset 语义，明确清空基线 compose 中的 `backend.gpus`，确保 CI 在无 GPU 环境可启动。

## 3. 影响范围
- 仅影响 CI 组合配置文件。
- 不影响本地默认 `docker-compose.yml` 的 GPU 行为（开发机仍可按原配置使用 GPU）。

## 4. 回滚方式
- 若需回滚，恢复 `.github/docker-compose.ci.yml` 到上一版（`gpus: []`）。

## 5. 感知方式
- `docker compose -f docker-compose.yml -f .github/docker-compose.ci.yml config` 输出中不再包含 `backend.gpus`。
- CI Start stack 阶段不再出现 `could not select device driver "" with capabilities: [[gpu]]`。
