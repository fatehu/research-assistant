# 论文阅读模块：右侧面板三段式卡片化层级重构说明（2026-02-16 06:38）

## 1. 目标
- 将右侧 `批注 / 评论 / 评分入库 / 询问` 面板统一升级为三段式信息层级：`标题区 -> 操作区 -> 列表区`。
- 在不改变现有业务逻辑的前提下提升可读性与操作聚焦性。

## 2. 变更范围（白名单）
- `frontend/src/pages/literature/PaperReaderPage.tsx`

## 3. 实现要点
1. 统一容器骨架
- 新增 `renderThreeTierPanel(title, subtitle, operations, listBlock)` 渲染器。
- 统一卡片背景、边框、分段分隔线和内边距。

2. 批注/评论/评分入库面板
- 操作控件集中在“操作区”。
- 历史列表统一下沉到“列表区”。
- 保持原有交互（新增、筛选、跳转、入库）不变。

3. 询问面板
- 参数配置、范围选择、会话选择、提问输入集中到“操作区”。
- 回答、会话记录、引用来源集中到“列表区”。
- 保留并兼容已实现的收藏夹入库就绪提示和章节跳转能力。

## 4. 用户可感知变化
- 面板层级更清晰，操作与结果区域视觉分离。
- 复杂的“询问”区域不再拥挤，排版更接近工作台风格。

## 5. 风险与回滚
- 仅改前端 UI 结构，无接口和数据变更。
- 回滚路径：恢复 `PaperReaderPage.tsx` 该次 UI 重构提交即可。
