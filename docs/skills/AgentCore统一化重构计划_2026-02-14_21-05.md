# AgentCore统一化重构计划（实施记录）

## 1. 目标
- 统一 `/api/chat/send` 与 `/api/codelab/notebooks/{id}/agent/chat` 的 Agent 执行内核。
- 引入 Agent 运行轨迹持久化（run/step）与上下文预算治理能力。
- 实现 `function calling` 优先、XML fallback、并行工具调用的一致执行路径。

## 2. 本次落地内容
- 新增 `AgentCore` 并保留 `ReActAgent` 兼容入口（继承别名）。
- `react_agent.py` 完成以下能力：
  - 动态工具描述注入（沿用 ToolRegistry 意图筛选）
  - function calling 主路径
  - XML 解析回退路径
  - 多工具并发执行（`parallel_safe` + 并发上限）
  - 上下文预算（滑窗 + 摘要注入 + observation 优先裁剪）
  - `<think>` 与用户历史分离（仅步骤侧记录）
  - run/step 持久化写入与完成态更新
  - 长期记忆读写开关接入（默认可关闭）
- 路由接入统一核心：
  - `backend/app/api/chat.py`
  - `backend/app/api/codelab.py`
  - `backend/app/api/notebook_agent.py`
  均通过 `create_react_agent(..., runtime_context=AgentRuntimeContext(...))` 调用同一执行内核。
- 新增 Agent 侧测试用例（5个）：
  - `test_agent_core_unified_routes.py`
  - `test_agent_context_budget.py`
  - `test_agent_function_calling_fallback.py`
  - `test_agent_parallel_calls.py`
  - `test_agent_step_persistence.py`

- `AGENT_LONGTERM_MEMORY_ENABLED`

## 4. 回滚策略
- 关 `AGENT_FUNCTION_CALLING_ENABLED`：回退 XML 主路径。
- 关 `AGENT_PARALLEL_TOOL_CALLS_ENABLED`：回退串行工具调用。
- 关 `AGENT_CONTEXT_BUDGET_ENABLED`：回退旧历史拼接策略。
- 关 `AGENT_PERSIST_STEPS_ENABLED`：关闭 run/step 落库。
- 关 `AGENT_LONGTERM_MEMORY_ENABLED`：关闭长期记忆读写。

## 5. 可观测性
- 运行日志新增/强化：
  - intent、selected_tools、prompt_desc_tokens
  - context_truncated
  - execution_time_ms/output_tokens_estimate/truncated（来自工具执行结果）
  - run 完成状态与 token 累计
