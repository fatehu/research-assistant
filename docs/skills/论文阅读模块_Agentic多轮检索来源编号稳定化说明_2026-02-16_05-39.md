# 论文阅读模块：Agentic 多轮检索来源编号稳定化说明（2026-02-16 05:39）

## 1. 目标
- 解决 Agentic 多次 `knowledge_search` 时 `[来源X]` 编号重复与冲突问题。
- 保证同一会话内来源编号“首次分配后稳定不变”。
- 保证 observation、最终回答、右侧来源列表的编号一致。

## 2. 改动范围
- `backend/app/api/literature.py`

## 3. 关键实现
### 3.1 工具级稳定编号
- 在 `LiteratureScopedKnowledgeSearchTool` 增加会话内状态：
  - `self._source_index_by_key`
  - `self._next_source_index`
- 来源键优先级：
  - `chunk_id` 存在时用 `chunk:{chunk_id}`
  - 否则退化为 `document_id + page + section_title + snippet` 哈希
- 每次检索先做“稳定编号映射”，再返回 `results` 与 `output`。

### 3.2 Agent observation 编号一致
- 在 `LiteratureAskAgentCore` 重写 `_compress_knowledge_observation`：
  - 不再按“本轮第几个结果”编号。
  - 改为使用 `row.idx`（稳定编号）生成 `[来源X]`。

### 3.3 多轮来源聚合
- 在 `agentic_stream` 中新增 `sources_by_idx` 聚合池：
  - 每次 observation 合并同编号来源。
  - 结束时按 `idx` 排序输出 `public_sources`。
- 不再覆盖为“最后一次检索结果”。

## 4. 效果
- 多轮检索后，回答中的 `[来源X]` 不会跨轮重号。
- 前端点击引用能稳定定位同一来源。
- 会话缓存里的 `sources` 也保持统一编号语义。
