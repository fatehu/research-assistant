# Agent一致性与引用约束增强说明（2026-02-12 22:07）

## 1. 本次更新解决的问题
在上一轮评估中发现两类短板：

1. 两套 Agent（AI 对话 / CodeLab）对知识库检索链路接入不一致。  
CodeLab 与 Notebook Agent 在创建 `ToolRegistry` 时传入 `db=None`，导致 `knowledge_search` 不会被注册，无法稳定走完整 RAG 检索链路。

2. 生成阶段的“引用约束”不够硬。  
虽然检索结果已有 `[来源X]`，但 ReAct 生成提示词未强约束“关键结论必须带来源”，存在回答不带引用或引用不规范的风险。

## 2. 使用了哪些技术
1. FastAPI 依赖注入（`Depends(get_db)`）  
2. ToolRegistry 条件注册机制（基于 `db` 与 `user_id`）  
3. ReAct 系统提示词增强（Prompt 约束）  
4. Observation 回写消息模板统一（减少分支漏约束）  
5. Pytest 单元测试（路由接线、注册行为、提示词约束）

## 3. 目的是什么
1. 让 AI 对话与 CodeLab/Notebook 两条 Agent 链路都能使用同一套知识库检索能力。  
2. 提升基于知识库回答时的可追溯性与可信度，减少“无引用结论”。

## 4. 怎么用的（实现方式）

### 4.1 Agent 检索一致性
1. `backend/app/api/codelab.py`  
- 在 `ToolRegistry` 初始化处把 `db=None` 改为 `db=db`，使 CodeLab Agent 可注册 `knowledge_search`。

2. `backend/app/api/notebook_agent.py`  
- 新增 `AsyncSession` 与 `get_db` 依赖。  
- `notebook_agent_chat`、`get_available_tools` 两个路由增加 `db: AsyncSession = Depends(get_db)`。  
- `NotebookToolRegistry` 初始化处改为传入 `db=db`。

### 4.2 引用约束增强
1. `backend/app/services/react_agent.py`  
- 新增 `CITATION_POLICY_PROMPT`，明确：
  - 基于 `knowledge_search` 回答时关键结论必须带 `[来源X]`；
  - 仅可使用 observation 中出现过的来源编号；
  - 证据不足要明确说明。  
- `_build_system_prompt` 统一拼接该引用规范。  
- 新增 `_build_observation_message(tool_name, observation_output)`：  
  - `knowledge_search` 分支注入更强引用要求；  
  - 其他工具保持通用 follow-up。
- 将多处分支内手写 observation 追问文案统一替换为该函数，避免规则不一致。

## 5. 做到了什么
1. CodeLab / Notebook Agent 已具备注册 `knowledge_search` 的必要前提（有 DB 会话时）。  
2. ReAct 在系统提示词和 observation 追问两层都加入了引用硬约束。  
3. 新增自动化测试覆盖关键行为，避免后续回归时被悄悄破坏。

## 6. 怎么感知效果
1. 功能层面：  
- 在 CodeLab / Notebook 场景中，Agent 可见工具列表将包含 `knowledge_search`（有 DB 时）。  

2. 回答质量层面：  
- 当 Agent 使用知识库结果后，最终回答更容易稳定保留 `[来源X]` 标注。  

3. 可维护性层面：  
- observation 追问文案统一到单点函数，后续改引用策略只需改一处。

## 7. 怎么测试
已新增并通过以下测试：

1. `backend/tests/test_tool_registry_knowledge_search.py`  
- 验证 `ToolRegistry` 仅在 `db` 可用时注册 `knowledge_search`。

2. `backend/tests/test_agent_db_wiring.py`  
- 验证 codelab 路由中 `ToolRegistry` 传入 `db=db`；  
- 验证 notebook_agent 关键路由已声明 `db` 依赖参数。

3. `backend/tests/test_react_agent_citation_policy.py`  
- 验证系统提示词含“知识检索引用规范”；  
- 验证 `knowledge_search` observation follow-up 包含强引用约束。
