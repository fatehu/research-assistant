# AgentCore统一化阶段2：知识库状态机事件推送改造说明（2026-02-16 08:08）

## 1. 本阶段目标
- 将知识库文档处理状态从高频轮询改为“事件流优先 + 低频轮询兜底”。
- 提升前端状态感知实时性，降低后端状态查询压力。

## 2. 改动文件白名单
- `backend/app/api/knowledge.py`
- `backend/app/services/status_event_bus.py`
- `frontend/src/pages/knowledge/KnowledgePage.tsx`
- `frontend/src/stores/knowledgeStore.ts`

## 3. 使用技术与做法
- 后端新增 SSE 订阅接口：`GET /api/v1/knowledge/events/stream`。
- 文档状态变更节点统一发布 `document_status` 事件。
- 前端优先消费状态流并增量 patch，轮询间隔从 3s 下调为 30s（仅处理中文档存在时启用）。

## 4. 达成效果
- 上传、处理中、完成、失败状态可实时推送。
- 轮询频率显著降低，减少“无效状态查询”。
- SSE 失败时自动降级到低频轮询，避免页面失效。

## 5. 风险与回滚
- SSE 中断时依赖降级轮询；若异常频发可临时关闭状态流逻辑。
- 事件总线异常不应阻断主流程，失败仅记录警告日志。
