# Tool 架构重构与动态选择（实施记录）

## 1. 目标
- 完成 Tool 基础能力增强：超时、重试、Schema 校验、输出 token 估算与截断。
- 修复重点工具问题：WebSearch 稳定回退、Calculator 安全求值、Literature 并行融合、WebScrape 合规控制。
- 实现基于意图的动态工具筛选，减少 System Prompt 冗余描述注入。

## 3. 关键实现
### 3.1 Tool 基础能力
- `EnhancedToolResult` 增加字段：
  - `execution_time_ms`
  - `output_tokens_estimate`
  - `truncated`
- 新增 `ToolBase`：
  - 统一入参校验（Pydantic）
  - 超时 + 重试机制
  - 结果统一封装（含 retry_attempt）
  - 输出 token 估算与智能截断（头尾保留）

### 3.2 Registry 与 DI 解耦
- 增加 `ToolDependencyContext`、`ToolProvider`、`DefaultToolProvider`。
- `ToolRegistry` 仅负责工具容器/执行，工具构建由 provider 注入。
- 保留 `get_tool_registry()` 与现有构造参数兼容。

### 3.3 KnowledgeSearch Pipeline 化
- 将 `KnowledgeSearchTool` 重构为 4 段：
  - `rewrite`
  - `retrieve`
  - `rerank`
  - `compress`
- `_execute_with_db` 仅保留 orchestrator。
- 检索 SQL、阈值、维度过滤条件保持行为等价。

### 3.4 WebSearch 稳定化
- 搜索链路：`Serper -> Tavily -> DDGS`。
- 移除 DuckDuckGo HTML 正则解析 fallback。

### 3.5 Calculator 安全求值
- 使用 `asteval` 替代 `eval()`。
- 增加危险表达式与标识符白名单约束。

### 3.6 Literature 并行融合
- `LiteratureService.search_multi()`：Semantic Scholar + arXiv + PubMed 并行。
- 去重优先级：DOI > arXiv ID > 归一化标题+年份。
- `source=multi` 已同步到 Agent 与 Notebook 两侧工具。

### 3.7 WebScrape 合规化
- 新增 `robots.txt` 检查（可配置开关）。
- 新增域名级最小请求间隔限速。
- 保留黑名单域名策略并补充错误码。

### 3.8 动态工具选择
- 意图分类：`knowledge_query / web_query / code_task / literature_task / general_chat`。
- `ToolRegistry.list_tools()`、`get_tools_description()` 支持按意图/白名单过滤。
- `ReActAgent` 构建系统提示词时仅注入相关工具描述，记录 `intent/selected_tools/prompt_desc_tokens`。
- `TOOL_SELECTION_ENABLED=false` 可回退全量注入。

### 3.9 Review 回修（2026-02-14 19:44）
- WebSearch fallback 稳定性修复：
  - 新增 `_safe_provider_call()`。
  - `Serper/Tavily` 调用即使出现 `httpx.RequestError` 或其他异常，也会返回结构化失败并继续执行后续 fallback（`DDGS`）。
- Tool Selection 意图识别修复：
  - 扩展 `knowledge_query` 关键词与正则（覆盖 `uploaded PDF/my document/根据我上传的文档` 等常见表达）。
  - 将知识库意图判断提前到 web 意图之前，避免“总结我上传 PDF”误判为 `general_chat`。
- Docker GPU 兼容性修复：
  - 移除 `docker-compose.yml` 中后端强制 `gpus: all`。
  - 保持 `docker-compose.gpu.yml` 作为 GPU 可选覆盖，GPU 主机通过 `-f docker-compose.gpu.yml` 开启，CPU 主机默认可启动。
