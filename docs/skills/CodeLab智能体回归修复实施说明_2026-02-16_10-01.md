# CodeLab 智能体回归修复实施说明（2026-02-16 10:01）

## 1. 背景与目标
- 背景：CodeLab 智能体出现三项回归：
  - RAG 未命中时仍展示“RAG 质量”卡片（全 0 指标）。
  - 推理过程（thought/action/observation）不再稳定显示。
  - Notebook 操作权限虽设计支持，但在部分场景不可用。
- 目标：在不破坏现有接口兼容性的前提下，恢复上述能力并完成前后端闭环。

## 2. 本阶段改造范围（白名单）
- `backend/app/api/codelab.py`
- `backend/app/services/agent_tools_impl/registry.py`
- `frontend/src/components/NotebookAgentPanel.tsx`
- `frontend/src/pages/chat/components/MessageBubble.tsx`
- `frontend/src/services/api.ts`

## 3. 关键实现
### 3.1 RAG 质量卡片按“实际使用”显示
- 前端 `parseRagMetrics` 改为“有实际 RAG 行为才返回指标”：
  - `knowledge_search_calls/source_labels_count/answer_citation_count/compression_calls/citation_repair_*` 任一大于 0 才展示。
- 影响文件：
  - `frontend/src/components/NotebookAgentPanel.tsx`
  - `frontend/src/pages/chat/components/MessageBubble.tsx`

### 3.2 恢复并持久化推理过程
- 后端 SSE 事件在 `thought/action/observation` 时累积 `react_steps`，并带 `iteration`。
- 结束时将 `react_steps` 写入历史消息 metadata，同时回传到 `done` 事件。
- 前端新增/扩展：
  - 接收 `iteration/react_steps` 类型字段。
  - 实时渲染流式推理步骤。
  - 历史消息回显 `react_steps`。
- 影响文件：
  - `backend/app/api/codelab.py`
  - `frontend/src/services/api.ts`
  - `frontend/src/components/NotebookAgentPanel.tsx`

### 3.3 恢复 Notebook 可操作性
- 工具路由层在 Notebook 上下文强制保留代码执行相关工具，避免意图误判为 `general_chat` 后丢失 Notebook 工具集。
- 扩充 code-task 关键词，覆盖绘图/数据分析高频表达（中英混合）。
- 前端授权开关改为始终可见（不再依赖“已有 cell 才显示”），空白 Notebook 也可先授权后操作。
- 影响文件：
  - `backend/app/services/agent_tools_impl/registry.py`
  - `frontend/src/components/NotebookAgentPanel.tsx`

## 4. 可观测性与回滚
- 可观测：
  - SSE 中可见 `thought/action/observation` 及 `iteration`。
  - 历史消息 metadata 可见 `react_steps`。
  - 非 RAG 回答不再显示“RAG 质量”卡片。
- 回滚：
  - 可按文件粒度回滚，优先回滚前端展示逻辑，再回滚后端 `react_steps` 扩展。

## 5. 验收口径
1. 非 RAG 回答不展示 RAG 指标卡片。
2. CodeLab 对话中可实时看到推理步骤，并在刷新历史后仍可回显。
3. 空白 Notebook 页面也能开启“允许 AI 操作”，并触发 notebook 工具调用。
