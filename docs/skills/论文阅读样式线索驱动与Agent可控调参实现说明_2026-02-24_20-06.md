# 论文阅读样式线索驱动与Agent可控调参实现说明（2026-02-24 20:06）

## 目标
- 解决“图片内容被误识别为正文文本”的问题（例如 `a1111111111`）。
- 把页面样式线索（字号、粗体、位置、图片重叠）提供给 Agent，提升结构修复质量。
- 在模板风格基础上增加“可控调参”，让 AI 自动微调排版而非固定死模板。

## 本次实现
1. 后端新增样式线索提取（style_cues）
- 使用 `pdfplumber.extract_words(extra_attrs=["fontname","size"])` 提取行级样式特征。
- 输出关键信息：
  - `median_font_size`
  - `heading_hints`（候选标题行）
  - `noise_hints`（疑似图片噪声文本）
  - `image_count`

2. 解析器融合样式线索
- 标题识别从“纯文本规则”升级为“文本规则 + 样式提示”。
- 对疑似噪声行执行过滤，降低图片区域误识别正文风险。

3. Agent 提示词升级
- 将 `style_context`（样式线索摘要）一并发送给 Agent。
- 新增约束：Agent 需忽略图片/装饰噪声文本。
- 新增返回字段 `style_tuning`，仅允许白名单数值：
  - `body_scale` in `[0.9, 1.25]`
  - `line_height` in `[1.55, 2.2]`
  - `heading_scale` in `[0.95, 1.35]`

4. 前端渲染支持可控调参
- 新增 `ReaderGenerativeStyleTuning` 类型。
- 生成式页面接收 `style_tuning` 并应用到：
  - 正文字号（body_scale）
  - 行高（line_height）
  - 标题字号（heading_scale）
- 保持模板白名单机制，不接受任意 CSS。

5. 修复隐藏稳定性问题
- 修复 `source_anchor.start_char=0` 被误判无效的问题（`or -1` 逻辑缺陷）。

## 结果
- Agent 生成结构时可参考页面样式信息，不再只看纯文本。
- 生成式 UI 由“模板固定值”升级为“模板 + Agent 可控微调”。
- 图片噪声文本误入正文概率降低。
