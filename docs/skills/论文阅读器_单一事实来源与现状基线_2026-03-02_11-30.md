# 论文阅读器：单一事实来源与现状基线（2026-03-02 11:30）

## 1. 目的
本文件替代近期分散的 Phase 文档，作为论文阅读器当前实现与后续整改的唯一基线说明。

## 2. 当前真实链路（以代码为准）
1. 结构提取：Document Mind DocStructure 为主链路（可降级）。
2. 结构标准化：后端将 DocStructure 映射为 `page_structure_v3`（含 `block_groups` / `relations` / `doc_nav_tree`）。
3. 建议层：Qwen3.5 读取 `page_structure_v3` 生成 `layout_advice_v3`（建议，不是最终裁决）。
4. 装配层：DeepSeek 通过 AgentCore 输出 `ui_ops`（增删改排组件），在后端做合同校验后应用。
5. 回填层：本地算法回填证据锚点（polygon 优先，bbox 兜底），前端渲染证据预览。

## 3. 已实现能力（确认）
1. DeepSeek 装配链路已接通：后端可发送 `component_patch` SSE，前端可增量应用。
2. 组件注册与前端 props 校验已存在：有 registry + Zod schema。
3. Document Mind 已切到 DocStructure 调用路径，支持结构提取元数据透传。

## 4. 当前问题（造成体验差的主因）
1. 装配模式仍是“初稿 + patch 修补”，不是“Agent 从空白画布主导设计”。
2. 组件体系仍偏阅读卡片，缺少图一风格所需的 Hero / 导航 / 营销化布局组件集合。
3. 段落和块的文本边界仍有不稳定，导致组件内容不完整或分裂。
4. 证据定位虽有 polygon，但仍存在错位与文本块不一致场景。

## 5. 统一约束（立即生效）
1. 正文内容来源以结构化 block 为准，禁止在装配层自由改写事实文本。
2. DeepSeek 负责组件装配决策；Qwen 建议层不做最终裁决。
3. 证据按钮和证据预览必须共用同一可行动锚点判定。
4. 匹配失败按节点降级，不允许整页清空。

## 6. 验收基线（下一轮开发必须对齐）
1. 一段一块：`ParagraphProse` 与 paragraph block 一对一。
2. 文本可追溯：组件文本必须可回溯到 `page_structure_v3.blocks`。
3. 定位可信：点击定位后，高亮区域与当前组件文本一致，不串块。
4. 生成稳定：同页重复生成不出现大幅随机结构抖动。

## 7. 文档收口策略
1. 本文件为“当前态”唯一入口，后续阅读器改造优先更新本文件。
2. 历史文档保留“有用的阶段结论”，但不再作为当前实现依据。
3. 本次已移除 2026-02-27 的 PhaseA-E 文档（skills/test），避免继续误导。

## 8. 下一步执行原则
1. 小步迭代，不做整链路大改。
2. 每次只修一个可观测问题（如：段落拆裂、定位错位、组件缺失）。
3. 每轮改动都附最小可复现样例页（优先 paper 78 的问题页）。
