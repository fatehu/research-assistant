# MCP阶段2内部工具MCP化与双路策略说明（2026-02-13 03:43）
- 记录时间：2026-02-13 03:43
- 实施阶段：MCP Phase 2（内部工具 MCP 化 + 外部优先双路策略）

## 1. 本次更新使用了哪些技术
1. FastMCP（`mcp.server.fastmcp.FastMCP`）封装内部 MCP Server。
2. 工具适配复用：直接复用现有 `WebSearchTool`、`WebScrapeTool`、`LiteratureSearchTool`。
3. 双路路由策略：`MCP_TOOL_ROUTES`（local tool -> external MCP tool 列表）。
4. 稳定性策略：超时（timeout）+ 重试（retry）+ 熔断（circuit breaker）。
5. Docker profile 拆分：`mcp_web`、`mcp_literature` 服务独立启停。

## 2. 目的是什么
1. 让现有高价值工具具备标准 MCP 形态，便于跨 Agent/跨进程复用。
2. 搜索与抓取优先使用外部成熟 MCP 能力，降低失败率。
3. 外部能力异常时自动回退本地工具，避免核心流程不可用。

## 3. 怎么用（实现方式）
1. 新增内部 MCP Server：
   - `backend/app/mcp_servers/web_server.py`
   - `backend/app/mcp_servers/literature_server.py`
   - `backend/app/mcp_servers/common.py`
2. ToolRegistry 新增双路执行逻辑（外部优先，失败回退）：
   - `backend/app/services/agent_tools.py`
   - 新增配置解析：`MCP_TOOL_ROUTES`
   - 新增稳定性参数：
     - `MCP_ROUTE_TIMEOUT_SECONDS`
     - `MCP_ROUTE_RETRY_ATTEMPTS`
     - `MCP_ROUTE_RETRY_BACKOFF_SECONDS`
     - `MCP_ROUTE_CIRCUIT_BREAKER_FAILURES`
     - `MCP_ROUTE_CIRCUIT_BREAKER_OPEN_SECONDS`
3. 配置透传：
   - `backend/app/config.py`
   - `docker-compose.yml`
   - `.env.example`
   - `.env`

## 4. 做到了什么
1. `web_search` / `web_scrape` 可按配置走“外部 MCP -> 本地工具 fallback”。
2. 双路策略可通过环境变量开关和调参，不改代码即可灰度。
3. MCP 路由失败具备退避重试和熔断保护，减少重复雪崩调用。
4. 内部 `web` / `literature` MCP Server 可独立以容器方式运行。

## 5. 怎么感知效果
1. 日志可见：
   - 路由成功：`[MCP] routed success local=... remote=...`
   - 路由失败：`[MCP] routed call failed ...`
   - 熔断打开：`[MCP] circuit opened route=...`
2. 业务侧感知：
   - 外部服务临时故障时，`web_search`/`web_scrape` 仍能返回本地结果。
   - 异常高峰期不会持续打满外部 MCP 端点。

## 7. 部署说明（Docker）
1. 启动基础服务：
```bash
docker compose up -d postgres redis backend frontend
```
2. 启动内部 MCP 服务（按需）：
```bash
docker compose --profile mcp up -d mcp_web mcp_literature
```
3. 在 `.env` 中配置：
```env
MCP_ENABLED=true
MCP_SERVERS=[{"name":"web_internal","transport":"streamable_http","url":"http://mcp_web:8091/mcp"},{"name":"literature_internal","transport":"streamable_http","url":"http://mcp_literature:8092/mcp"}]
MCP_TOOL_ROUTES={"web_search":["mcp.brave.search","mcp.exa.search"],"web_scrape":["mcp.firecrawl.scrape"]}
```
4. 说明：`MCP_TOOL_ROUTES` 中外部工具全部失败时，会自动回退本地同名工具。
