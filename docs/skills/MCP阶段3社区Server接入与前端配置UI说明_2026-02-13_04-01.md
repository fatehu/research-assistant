# MCP阶段3社区Server接入与前端配置UI说明（2026-02-13 04:01）
- 记录时间：2026-02-13 04:01
- 实施阶段：MCP Phase 3（社区 MCP Server 接入 + 前端配置 UI）

## 1. 本次更新使用了哪些技术
1. MCP 配置解析增强：
   - 同时支持 `MCP_SERVERS`（JSON 数组）
   - 支持 Claude Desktop 风格 `{"mcpServers": {...}}`
   - 支持配置文件加载/保存（`MCP_CONFIG_PATH`）
2. FastAPI 管理接口：
   - `/api/mcp/templates`
   - `/api/mcp/config`
   - `/api/mcp/config/validate`
   - `/api/mcp/config`（PUT 保存）
   - `/api/mcp/status/refresh`
3. 社区模板机制：
   - filesystem / postgres / github / brave / exa / firecrawl 模板
4. 前端设置页 UI：
   - 模板套用
   - JSON 编辑
   - 配置校验
   - 配置保存
   - 连通性探测

## 2. 目的是什么
1. 把 MCP Server 接入从“改后端环境变量”升级为“可视化配置”。
2. 降低接入社区 MCP Server 的门槛，支持快速模板化落地。
3. 让 MCP 配置可审计、可验证、可持久化，减少线上误配风险。

## 3. 怎么用（实现方式）
1. 后端配置解析增强：
   - `backend/app/services/mcp/config.py`
   - 新增 payload 解析、文件加载、文件保存、格式互转函数
2. 社区模板：
   - `backend/app/services/mcp/templates.py`
3. MCP 管理 API：
   - `backend/app/api/mcp.py`
   - `backend/app/main.py` 注册路由 `prefix=/api/mcp`
4. ToolRegistry 配置源扩展：
   - `backend/app/services/agent_tools.py` 在创建 MCP Client 时读取 `MCP_CONFIG_PATH`
5. 前端配置 UI：
   - `frontend/src/services/api.ts` 新增 `mcpApi`
   - `frontend/src/pages/user/SettingsPage.tsx` 新增 MCP 卡片
6. 环境与部署：
   - `backend/app/config.py` 新增 `mcp_config_path`
   - `.env.example` / `.env` / `docker-compose.yml` 新增 `MCP_CONFIG_PATH` 与社区 Server 常见密钥变量位

## 4. 做到了什么
1. 后端可接收并校验两种主流配置格式（列表格式与 Claude 格式）。
2. MCP 配置可通过 API 保存到文件，运行时可由 `ToolRegistry` 读取。
3. 前端“设置页”可直接完成配置闭环：模板 -> 编辑 -> 校验 -> 保存 -> 探测。
4. 社区 MCP（filesystem/git流程/database/search/scrape）具备模板化接入入口。

## 5. 怎么感知效果
1. 前端设置页新增 “MCP Server 配置”卡片。
2. 配置校验成功后会提示解析到的 Server 数。
3. 连通性检查会返回每个 Server 的可达状态和发现的工具数量。
4. 后端日志可观测到 MCP 配置路径与工具发现结果。

## 7. 部署方法（本地/容器）
1. 确保环境变量：
```env
MCP_ENABLED=true
MCP_CONFIG_PATH=mcp_servers.json
MCP_TOOL_PREFIX=mcp
MCP_TOOL_ROUTES={"web_search":["mcp.brave.search","mcp.exa.search"],"web_scrape":["mcp.firecrawl.scrape"]}
```
2. 启动服务：
```bash
docker compose up -d backend frontend
docker compose --profile mcp up -d mcp_web mcp_literature
```
3. 打开前端设置页，进入 MCP Server 配置卡片：
   - 选择模板并套用
   - 校验配置
   - 保存配置（写入 `MCP_CONFIG_PATH` 文件）
   - 连通性检查
