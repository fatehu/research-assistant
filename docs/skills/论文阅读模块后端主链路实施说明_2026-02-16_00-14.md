# 论文阅读模块后端主链路实施说明（阶段）

- 时间：2026-02-16 00:14
- 范围：文献阅读模块后端主链路（阅读会话、批注、评论、评分、入库、询问）与前端 API 契约对接

## 1. 本阶段目标

- 在现有文献模块上完成以下可运行能力：
- 阅读会话 `GET/PUT /api/v1/literature/papers/{paper_id}/reader/session`
- 批注 CRUD `.../annotations`
- 评论 CRUD `.../comments`（支持 `all|same_group`，限制一级回复）
- 评分写入与汇总 `.../rating` + `.../ratings/summary`（全站均分 + 同组均分）
- 入库链路 `.../add-to-knowledge` + `.../knowledge-links`（状态 `pending|processing|ready|failed`）
- 询问 SSE `POST /api/v1/literature/ask`（事件 `start|token|sources|done|error`）

## 2. 关键实现点

- 新增并接入 `literature` 扩展数据模型（已在前置阶段创建模型/迁移）：
- `paper_entities`, `paper_read_sessions`, `paper_annotations`, `paper_comments`, `paper_ratings`, `paper_knowledge_links`, `literature_qa_sessions`, `literature_qa_messages`
- 在 `backend/app/api/literature.py` 增加：
- 论文实体归并（DOI > arXiv > title+year）
- 同组并集去重逻辑（基于 `group_members`）
- 评论权限治理（作者或管理员可编辑/删除）
- 复用 `knowledge` 文档处理任务，替代空实现 `process_document_background`
- 新增问答缓存（Redis 优先，失败自动降级内存，TTL 10 分钟）

## 3. 前端契约对齐

- 在 `frontend/src/services/api.ts` 补充文献阅读模块类型与 API：
- 阅读会话、批注、评论、评分、入库链路
- 询问流式 `askStream`
- 新增阅读工作台页面：`frontend/src/pages/literature/PaperReaderPage.tsx`
- 新增路由：`/literature/:paperId/read`
- 在论文详情面板新增“阅读工作台”入口按钮

## 5. 风险与后续

- Alembic 在本机执行需要可用数据库连接；当前环境凭据不可用（详见测试记录）。
- 当前已完成“后端主链路 + 前端 API 契约”，下一阶段建议补 `PaperReaderPage` 与 store 状态联动，以及端到端回跳交互。
