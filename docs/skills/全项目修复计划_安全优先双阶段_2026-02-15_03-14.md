# 全项目修复计划（安全优先，双阶段）实施记录

## 1. 本次目标

- 落地 P2 关键项：导师分组成员真实化、学生动态真实 API、前端路由拆包与关键页面 hooks 依赖治理。

## 2. 后端改动

### 2.1 CodeLab 沙箱执行
- 新增 `backend/app/services/codelab_executor.py`：
  - 每个 notebook 使用独立子进程 worker 执行代码。
  - 默认启用策略检查（AST + import/call 黑名单）。
  - 强制硬超时，超时后重启 worker。
  - 返回 `terminated_reason` / `policy_violation_code`。
  - 提供变量快照与预览接口（供上层展示）。
- 改造 `backend/app/api/codelab.py`：
  - `ExecuteResponse` 新增 `terminated_reason`、`policy_violation_code`。
  - `PythonKernel` 在 `CODELAB_SANDBOX_ENABLED=true` 时走 `CodeLabExecutor`。
  - 增加用户并发执行限制（`CODELAB_MAX_CONCURRENCY_PER_USER`），超限返回 `resource_limit`。
  - `POST /api/codelab/execute` 增加保护：
    - `CODELAB_DIRECT_EXECUTE_ENABLED=false` 默认关闭。
    - 开启后仍要求管理员角色或 `DEBUG=true`。
  - 增加执行日志字段：`user_id/notebook_id/terminated_reason/execution_time_ms`。

### 2.2 CORS 与建表策略
- 改造 `backend/app/config.py`：
  - 新增配置：
    - `CODELAB_SANDBOX_ENABLED`
    - `CODELAB_EXEC_TIMEOUT_HARD_SECONDS`
    - `CODELAB_MAX_CONCURRENCY_PER_USER`
    - `CODELAB_DIRECT_EXECUTE_ENABLED`
    - `CORS_ALLOW_ORIGINS`
    - `AUTO_CREATE_TABLES`
  - 新增 `get_cors_allow_origins()`。
- 改造 `backend/app/main.py`：
  - CORS 读取 `CORS_ALLOW_ORIGINS`，不再硬编码 `*`。
  - 若配置包含 `*` 且 `allow_credentials=true`，启动即报错。
  - `AUTO_CREATE_TABLES=false` 时跳过 `create_tables()`。

### 2.3 导师动态与组成员接口
- 改造 `backend/app/api/mentor.py`：
  - 新增 `GET /api/mentor/groups/{group_id}/members`。
  - 新增 `GET /api/mentor/activities`（对话/Notebook/知识库/论文四源融合，按时间倒序，支持分页）。

### 2.4 CodeLab/Agent 兼容层调整
- 改造 `backend/app/api/agent.py`、`backend/app/services/notebook_tools.py`：
  - 不再直接依赖 `kernel.namespace` 读取变量值。
  - 改为 `get_variables()` + `get_variable_preview()` + `has_variable()` 兼容沙箱内核。
