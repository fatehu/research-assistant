  - `frontend/src/services/api.ts`
- 修复方案：

  4. 前端解析器先读顶层 `{code,message,details}`，再回退 `detail`。
  5. 新增错误契约回归测试（多端点抽样）。
- 回归测试：
  - `python -m pytest backend/tests/test_knowledge_error_contract.py -q`

  - `npm run lint`

  - 仅保留前端兼容解析层，后端可逐路由回滚
