# 系统功能点与代码映射（2026-04-26）

本文基于当前仓库代码、README、测试文件清单、已执行的定向测试和历史测试记录整理。目标是说明系统实际包含哪些业务能力、主要由哪些代码承载、哪些测试覆盖了这些能力，以及当前可确认的边界。

## 1. 总体定位

本系统是面向科研工作的全栈平台，不是单一 Chat，也不是单一文献库。核心能力由以下模块协同完成：

- 主 Agent：理解用户诉求、规划任务、选择工具、组织证据、维护上下文和引用。
- 检索层：公网搜索、学术检索、知识库检索、Zoekt 文件检索。
- 文献库：论文搜索、入库、PDF 下载、收藏、分类、阅读、问答、注释和知识库链接。
- PDF/PDF2MD：把论文 PDF 解析为 Markdown、结构块、页面资产和可检索内容。
- Reader Generative UI：把论文页面转换为受约束的交互式阅读体验。
- 文献综述 workspace：围绕主题收集论文、下载 PDF、生成单篇 review 和最终综述。
- Project/runtime-worker：执行论文复现、代码运行、调试和优化。
- CodeLab：提供轻量 Notebook/Python 实验环境。
- 文档 artifact：把长文写作拆成可编辑 block，让用户和 Agent 协作。
- 模板管理和 DOCX：管理写作模板，分析约束，调用 Claude document skill 生成和精修 Word。

## 2. 主 Agent、工具调用和上下文管理

### 功能点

- Chat SSE 对话：支持流式 start、phase、action、observation、content、done、error。
- ReAct 工具循环：模型可以调用本地工具、MCP 工具和业务工具。
- 工具错误契约：工具失败时返回统一结构，避免把异常堆栈直接暴露给模型。
- 工具结果截断：工具结果进入上下文时按预算处理，避免全文工具输出压爆上下文。
- 引用管理：公网搜索、知识库和工具来源可以形成 citation index，供回答中的 `[网页X]`、`[来源X]` 回填。
- 上下文预览：发送前估算当前消息、历史、工具、RAG、skill prompt 和 token 使用。
- 会话状态：维护 `context_state`、`turn_store`、`item_stream` 和 tool ledger。
- 自动压缩和手动压缩：长对话可做 compaction，保留稳定事实和当前任务状态。
- 背景 run：长任务可绑定 conversation，支持 active-run、run stream 和 cancel。
- Branch：把当前对话复制到新会话，保留消息、turn、metadata 和 artifact 快照。
- 消息局部改写：支持对 assistant 消息选区改写。
- Artifact 局部改写：支持对 document artifact block 的选区改写。

## 3. Skill 系统

### 功能点

- 本地 skill 发现：从 `.agents/skills/*/SKILL.md` 和 `skill.yaml` 读取 skill。
- Skill 元数据：支持 name、description、aliases、trigger keywords、channels、stages、artifacts、blocked tools、enforced tools。
- Skill UI 元数据：支持 `agents/openai.yaml` 中的 display name、short description、default prompt 和 policy。
- 会话级常驻：skill 激活后，可以把 session system prompt 和 skill prompt 持久带入后续回合。
- 显式激活：用户可以通过 skill 名称、别名或 `activate_skill` 激活。
- 隐式激活策略：`allow_implicit_invocation=false` 时，trigger keyword 不应自动激活，但显式名称仍可激活。

## 8. Reader Generative UI

### 功能点

- Reader composed page：从 PDF 页面、结构块、图表和上下文生成 composed payload。
- Generative plan：根据页面 dossier、用户意图和工具结果生成阅读计划。
- Experience Plan：把 plan 转换为读者可见的阅读体验。
- Experience V2：引入 reading dossier v2、experience session v2、page artifact v2。
- Page Artifact V2：受约束的页面阅读 artifact，包含 heading、excerpt、paragraph、figure slot、term note、external resource。
- Renderer contract：校验组件白名单、props、anchor 和 renderability。
- Inline query：对 composed reader 节点进行局部问答。
- Block explain：对 Experience V2 的指定 block 或图块做局部讲解。
- Block rewrite：对 Experience V2 block 做局部改写。
- Figure/page assets：提供图块、页面图像和 grounding page asset 流。
- Review/Publish：支持 reader composed review session、截图观察、自动 patch 和发布。
- Cache：Redis/DB/memory 多层缓存，支持 fast path 和 stable artifact 回填。
