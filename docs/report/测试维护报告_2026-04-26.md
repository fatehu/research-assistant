## 主要维护点

### Skill 激活

涉及文件：

- `backend/app/services/agent_skill_service.py`

维护内容：

- 修正 skill keyword 命中时的隐式激活行为。
- 对 `allow_implicit_invocation=false` 的 skill，keyword 只作为候选，不直接激活。
- 显式名称、alias、manifest name 仍然允许激活。

覆盖意义：

- 避免用户普通描述误触 skill。
- 保留用户明确指定 skill 时的可用性。

### Chat 发送与上下文状态

涉及文件：

- `backend/tests/test_chat_send_api.py`

维护内容：

- fake runtime 增加 conversation context state 存取能力。
- 调整重复 bind 测试断言，使其匹配当前上下文持久化行为。

覆盖意义：

- 保证 Chat send API 在带上下文状态时仍能稳定测试。
- 避免测试 fake 与实际 runtime contract 脱节。

### Literature schema 的 legacy adjacent payload 防护

涉及文件：

- `backend/app/schemas/literature.py`

维护内容：

- 对 legacy JSON payload stuffing 场景保持 fail-loud。
- 避免 silently drop 后被当成合法 adjacent item 继续流入 Reader。

覆盖意义：

- Reader adjacent context 不再悄悄吞掉高风险旧格式。
- 保持已有 contract test 的保护力度。

### Reader compose 对 fake paper 的兼容

涉及文件：

- `backend/app/services/literature_reader_compose_service.py`

维护内容：

- `_build_initial_ui_plan` 对 `title`、`venue`、`year`、`authors`、`doi`、`pdf_url`、`url` 使用防御式读取。

覆盖意义：

- 单测里的轻量 `SimpleNamespace` paper 不需要补齐真实 ORM 所有字段。
- 避免测试假对象缺字段导致无关崩溃。

### Reader API 测试适配

涉及文件：

- `backend/tests/test_literature_reader_api.py`

维护内容：

- 为直接调用 endpoint 的测试补 selected KB normalizer fixture。
- 对未挂载 docs fixture 的环境增加 sample fallback。
- 更新 figure asset version 断言。
- 更新 block explain stream 调用签名。
- fake artifact draft generator 补齐 mandatory resource request 生成。

覆盖意义：

- Reader API 测试可以在 Docker backend 容器内稳定运行。
- 降低测试对宿主机 docs fixture 挂载状态的依赖。

### Reader composed/generative 测试适配

涉及文件：

- `backend/tests/test_literature_reader_composed.py`
- `backend/tests/test_literature_reader_generative.py`

维护内容：

- endpoint 测试改为 patch `async_session_factory`，匹配当前接口签名。
- geometry 断言从旧的固定 `1360x1760` 改为不低于 grounding 尺寸。
- page image 允许命中本地缓存路径，例如 `paper_85/grounding_pages/page_8.png`。
- AI reconstruction mode 断言更新为当前 `fully_reconstructed` 语义。
- prompt 文案断言更新为当前图像裁剪策略。
- AI reconstructed figure asset 版本断言更新为 `v4_direct_ai_crop_q92`。
- single-agent refresh 测试补 mock `_panel_plan_agent.run`，避免误触真实 LLM。

覆盖意义：

- 测试跟上当前 Reader grounding、page image localization、AI reconstruction、SSE endpoint 的实际 contract。
- 消除单测误调用真实模型的问题。
