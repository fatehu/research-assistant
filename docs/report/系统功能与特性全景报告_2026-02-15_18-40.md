## 1. 系统概览

本系统是面向科研团队协作的 AI 平台，当前已形成“对话、知识库、文献、代码实验室、角色协作、共享与公告、MCP 扩展、自动化回归”八大能力域。

后端 OpenAPI 统计（当前运行实例）：

- 路径数：119
- 操作数（GET/POST/PUT/PATCH/DELETE）：162
- 对外统一 API 前缀：`/api/v1/*`

## 3. 核心功能清单

### 3.1 认证与账号体系

- 用户注册、登录、登出、`/auth/me` 登录态确认。
- 个人资料查询与更新。
- 密码修改（含旧密码校验）。
- 多角色账号模型：`admin`、`mentor`、`student`。

### 3.2 AI 对话能力

- 会话创建、查询、删除、归档。
- 消息历史查询与关键字检索。
- 流式对话发送（`/api/v1/chat/send`）。
- 停止生成消息落库，支持用户可追溯。
- 多 LLM Provider 抽象层（DeepSeek/OpenAI/阿里云/Ollama）。

### 3.3 知识库与 RAG 能力

- 知识库创建、更新、删除、列表、可见范围查询。
- 文档上传、处理状态轮询、分片查询、删除。
- 向量检索（多知识库、TopK、阈值、上下文拼接）。
- 嵌入模型列表动态下发。
- 本地/API 嵌入统一服务，支持维度策略与重建策略。

### 3.4 智能分块能力

- 预设策略管理：FAST、PRECISE、ACADEMIC、DEEP、DEFAULT。
- 文档结构分析（学术结构识别）。
- 分块预览、策略对比。
- 知识库级分块配置读写与预设应用。

### 3.5 文献管理能力

- 文献初始化与检索。
- 论文入库、详情、修改、删除。
- 收藏夹创建、修改、删除。
- 收藏夹与论文的增删关联。
- PDF 下载能力。

### 3.6 CodeLab 与 Notebook Agent

- Notebook 管理：创建、更新、删除、列表、详情。
- Cell 管理：新增、删除、执行。
- 内核能力：状态查询、中断、重启、Run-All。
- 直接执行入口（受权限与策略约束）。
- Notebook Agent 能力：
  - 对话问答
  - 代码建议
  - 错误解释
  - 数据分析
  - 工具列表与历史记录管理
- Notebook ReAct Agent 路由与 codelab 主链路并行存在。

### 3.7 MCP 管理与扩展能力

- MCP 配置读取、校验、持久化。
- MCP 模板下发（filesystem、postgres、github、web search 等）。
- MCP 状态刷新与工具数量统计。
- MCP server 生命周期与调用结果标准化封装。

### 3.8 角色协作能力

- 管理员：
  - 用户 CRUD
  - 角色切换
  - 启停账号
  - 系统统计
- 导师：
  - 学生邀请、移除
  - 研究组 CRUD
  - 组成员增删
  - 学生进度查看
- 学生：
  - 申请导师、离开导师
  - 导师检索与候选列表
  - 共享资源查看
  - 学生公告查看/已读

### 3.9 资源共享能力

- 支持分享资源类型：
  - 知识库
  - 论文
  - 论文集合
  - Notebook
- 支持单条与批量分享。
- 支持“共享给我”视图与计数。
- 支持将共享资源复制到个人库（论文/集合）。
- 支持撤销分享。

### 3.10 公告与邀请能力

- 公告创建、修改、删除、查询、阅读状态。
- 邀请收发与生命周期管理（accept/reject/cancel）。
- 待处理计数与收件箱视图。

## 5. 系统级非功能能力

### 5.1 安全与配置硬化

- `APP_ENV` 环境分级（development/staging/production）。
- 在 `staging/production` 强校验：
  - 弱 `SECRET_KEY` 拒绝启动
  - 弱或空 `DATABASE_URL` 拒绝启动
  - 启用 runner 时缺失 `CODELAB_RUNNER_TOKEN` 拒绝启动
- Compose 中敏感变量改为必填，不再弱 fallback。

### 5.2 API 版本治理与限流

- 对外 API 已切换为 `/api/v1/*`。
- 限流已启用（Redis 优先、内存降级）：
  - 超限返回 `429`
  - 响应头包含 `X-RateLimit-*`
  - 返回 `Retry-After`
- 限流分组（默认）：
  - 认证 20/min/IP
  - 对话 60/min/user
  - 知识检索 120/min/user
  - CodeLab 30/min/user

### 5.3 错误治理

- 新增统一业务异常模型 `AppServiceError`。
- 全局错误处理注册 `register_error_handlers(app)`。
- 关键链路 broad catch 增量守卫脚本：
  - `backend/checks/check_no_new_broad_excepts.py`

### 5.4 CodeLab 沙箱化执行

- 新增独立 `codelab-runner` 服务。
- 内部 API：
  - `POST /internal/codelab/execute`
  - `POST /internal/codelab/reset`
  - `GET /internal/codelab/variables`
  - `POST /internal/codelab/close`
  - `GET /internal/healthz`
- runner 异常时主服务返回 `503` + `sandbox_runner_unavailable`，不静默降级。
