## 手动验收点

### 表格页

- 顶部是否恢复显式 `证据 / 预览`

- 点击整表 `证据` 时是否回到整表定位

- 顶部不要再把完整 caption 重复成 card title，caption 只保留在表格下方
- 数值列应自动居中，整体样式更接近学术表而不是满格 spreadsheet

### 公式页

- 是否先看到原公式证据图
- 公式正文是否经过 KaTeX 渲染，而不是单纯原始字符串
- trailing `where ...` 是否变成解释文本，而不是和公式主体混在一起

- 复杂 `rowspan / colspan` 表格仍需下一轮继续做更高保真重建
- 公式 OCR 如果本身极差，KaTeX 仍可能只能部分改善；当前通过“原图证据 + 渲染文本”双轨兜底
