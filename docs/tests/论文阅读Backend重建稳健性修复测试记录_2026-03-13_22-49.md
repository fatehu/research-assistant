# 论文阅读 Backend 重建稳健性修复测试记录

时间：2026-03-13 22:49

## 问题基线

正式 backend 重建在 torch 安装阶段失败，错误为：

- `ERROR: THESE PACKAGES DO NOT MATCH THE HASHES FROM THE REQUIREMENTS FILE`

并且来自：

- `https://download.pytorch.org/whl/cu121/torch-2.5.1%2Bcu121-cp311-cp311-linux_x86_64.whl`

## 本轮目标

1. Dockerfile torch 安装步骤支持自动重试
2. 不改变 `TORCH_INDEX_URL` 的本地/CI 分流
3. 重跑 backend-only 构建，确认不再因为单次下载抖动立即失败

## 待验证

- `python3 -m py_compile` 不适用
- `docker build -t research-assistant-backend:latest ... -f backend/Dockerfile backend`
- `docker compose up -d --force-recreate backend codelab-runner`

## 结果

### Dockerfile 修复

- 新增 `ARG TORCH_PACKAGE=torch`
- 将单次 `pip install torch` 改为最多 `3` 次重试
- 失败时显式打印重试信息并延迟后再尝试
